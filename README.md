# UpRight Now

노트북 공부 중 **내가 등록한 편안한 자세 기준**에서 벗어난 변화를 조용히 알아차리고,
회복할 때마다 거북이 캐릭터가 기린으로 성장하는 자세 회복 스터디 웹앱.

- **Production**: https://upright-now.vercel.app
- **GitHub**: https://github.com/suhyunkim1105-hash/upright-now
- **릴리스 태그**: `v1.0.0-mvp` (이전 안정점 `stable-posture-mvp`)
- **문서 기준일**: 2026-07-26 · 기준 커밋 `44f4a92`

> 이 README와 `docs/` 안의 **현재 단일 기준** 문서가 저장소의 최신 기준입니다.
> 문서 분류는 [docs/DOCS_INDEX.md](docs/DOCS_INDEX.md)를 보세요.

## 1. 핵심 사용자

- 시험·과제·코딩·디자인 작업으로 **노트북 앞에 오래 앉아 있는 대학생**
- 하루 3~6시간 노트북 사용, 도서관·기숙사·자취방·카페를 옮겨 다님
- 기존 자세 알림 앱을 **반복 경고 피로** 때문에 꺼 본 경험이 있음
- 카메라 영상이 저장·전송되는 것을 걱정함
- 캐릭터 성장·친구와의 공동 목표에 흥미를 느낌

학습 프로필 3종으로 상황을 나눕니다 — **도서관 · 내 공간 · 팀플**.

## 2. 자세 관리와 게임의 관계

제품 무게중심은 **자세 관리 70% · 스터디 게임 30%** 입니다.
게임은 자세 관리를 반복하게 만드는 보조 장치이고, 게임을 빼도 자세 기능은 그대로 성립합니다.

```text
개인 기준 등록(5초)
→ 기준에서 벗어남 (warning → bad 5초 지속)
→ 회복 기회 열림 (30초 창)
→ 기준으로 돌아와 good 5초 유지
→ 회복 성공 = 마감괴수 특수 공격 + XP + 잎사귀
→ 캐릭터 성장 · 상점 · 친구 방 공동 보스
```

핵심 원칙 — **내 자세가 게임 컨트롤러가 된다.**
게임 버튼을 따로 누르지 않고, 실제 회복 행동만이 공격과 성장으로 이어집니다.

지키는 선:

- 개인 기준 **대비 상대 변화**만 판정합니다. 의료적 정상/비정상, 거북목, CVA, 통증을 판정하지 않습니다.
- 자세나 시선으로 **집중 여부를 추론하지 않습니다.** 세션 시간은 시작 버튼을 누른 시점부터 잽니다.
- 평균 자세 점수·등급을 **표시하지 않습니다.**

## 4. 개인 세션

- **길이**: 25분 집중 + 2분 리셋(기본) · 15분+1분 · 50분+5분 · 3분 데모+1분
- **시간 측정**: 시작 버튼을 누른 시점부터. `away`·`unstable` 에서도 타이머는 흐르고 **보상 판정만 멈춥니다.**
- **집계 분리**: 세션 시간 / 감지 가능 시간 / 자리 비움 시간을 각각 따로 기록합니다.
- **완주 인정**: 타이머 정상 종료 **또는** 계획 시간의 80% 이상 진행 후 종료.
  그 미만의 중도 종료는 기록만 남고 완주 보상·출석은 0입니다.
- **자리 비움**: 60초 이상이면 계속 / 일시정지 / 종료를 묻습니다. 벌점은 없습니다.
- **종료 단일 진입점**: `finalizeSession()` 이 세션당 한 번만 실행되어 중복 보상을 막습니다.

### 보상

| 행동 | XP | 잎사귀 | 개인 보스 피해 |
|---|---:|---:|---:|
| 자세 회복 성공 | 30 | 10 | 40 |
| 세션 완주 | 100 | 100 | 100 |
| 스트레칭 완료 | 20 | 20 | (방어막) |
| 목표 완료 자기보고 | 20 | 20 | — |

- 회복 XP·포인트는 **세션당 최대 5회**까지만 적립됩니다(회복 횟수 자체는 계속 기록).
- 모든 적립은 `applyReward()` 한 곳만 통과하며, 같은 이벤트 id 는 두 번 적용되지 않습니다.
- 개인 마감괴수 `마감괴수 D-DAY` 기본 체력 1000, 3단계 연출(calm / angry / rage).

## 5. 6단계 캐릭터

성장 단계는 **누적 XP에서 파생**합니다. 별도 stage 값을 저장하지 않고, 자세가 나빠져도 단계가 내려가지 않습니다.

| Lv | 이름 | 필요 XP | 달라지는 모습 |
|---:|---|---:|---|
| 1 | 뽀각 거북 | 0 | 목을 완전히 숨긴 큰 등껍질 |
| 2 | 꿈틀 거북 | 250 | 머리와 짧은 목 등장 |
| 3 | 빼꼼 거부기린 | 600 | 짧은 기린 목·작은 뿔·큰 등껍질 |
| 4 | 반듯 거부기린 | 1000 | 중간 길이 목과 세워진 몸통 |
| 5 | 쭉쭉 기린 | 1500 | 완전한 기린 체형과 긴 목 |
| 6 | 우뚝 기린 | 2200 | 가장 긴 목·과잠·백팩·당당한 표정 |

세션 중 **표현 상태**(idle · warning · slouch · recover · attack · away)는 장기 성장 단계와 완전히 분리됩니다.

## 6. 성장 · 상점

- **XP**: 성장 단계 파생 전용. **잎사귀 포인트**: 상점 결제 전용. 두 통화는 분리되어 있습니다.
- 상점은 **첫 정상 세션 완주 후** 잠금 해제됩니다.
- 과잠 4종(네이비·버건디·포레스트·코랄, 각 100P) · 백팩 3종(새내기·도서관·팀플, 각 80P)
- 과잠 1개 · 백팩 1개까지 동시 장착. 중복 구매·포인트 부족은 코드에서 차단됩니다.
- 실제 의상 이미지 레이어가 준비되기 전까지는 **색 리본 + 아이콘 배지**로 표시합니다
  (`equippedJacketId` / `equippedBackpackId` 분리를 유지해 이미지 레이어로 교체하기 쉽게 두었습니다).
- 실제 학교 로고·마스코트는 사용하지 않습니다.

## 7. 스트레칭

- 6종: 어깨 돌리기 · 날개뼈 모으기 · 손목/전완 · 앉은 등 회전 · 목 좌우 · 종아리 올리기 (30~45초)
- 학습 프로필별 **가중 랜덤**, 직전에 나온 동작은 제외합니다.
- 일시정지 · 다시 시작 · 다른 동작 · 완료 · 건너뛰기 제공. **건너뛰기에 불이익이 없습니다.**
- 완료하면 +20 XP / +20P, 친구 방이면 공동 방어막 +15.
- 통증·어지럼증 시 중단 안내를 항상 함께 표시하며, 의료 처방이 아닙니다.

## 8. PIP (미니 위젯)

- **Document Picture-in-Picture** 기반 별도 작은 창 (Chrome/Edge 116+)
- 설정에서 **세션 시작 시 자동 열기**를 켜고 끌 수 있습니다.
- PiP 창은 오프너와 같은 JS 컨텍스트를 공유해 **별도 타이머·자세 엔진 없이** 기존 store 를 그대로 구독합니다.
- **카메라 원본 영상은 PiP 에 들어가지 않습니다.** 캐릭터·남은 시간·자세 문구·회복 콤보만 표시합니다.
- 미지원 브라우저이거나 창 열기가 차단되면 **화면 안 미니 위젯으로 자동 대체**되고,
  PiP 실패·닫힘이 세션을 중단시키지 않습니다.
- 브라우저 정책상 창 열기는 사용자 클릭 체인 안에서만 가능하므로, 세션 시작 버튼 핸들러에서 요청합니다.

## 9. 친구 방

- **최대 2명**, 6자리 코드 또는 초대 링크로 입장. 회원가입 UI 없이 Supabase **익명 인증**만 사용합니다.
- 두 사람 모두 `준비 완료` 여야 방장이 시작할 수 있습니다.
- 각자의 자세는 **각자 기기에서만** 분석하고, 공유하는 것은 성공 이벤트뿐입니다.
- 공동 마감괴수 HP **2000** · 회복 −40 · 완주 −100 · 기린 싱크 −60 · 스트레칭 방어막 +15
- **기린 싱크**: 서로 다른 두 사람의 회복이 10초 안에 발생하면 합동 공격 1회.
  두 회복 uuid 를 XOR 한 파생 id 로 호출해 DB 가 정확히 한 번만 적용합니다.
- HP 의 최종 기준은 **DB `rooms.boss_hp`** 이며 `apply_room_damage` / `apply_room_shield` RPC 로만 원자적으로 변경됩니다 (event_id 중복 차단).
- 연결이 끊기면 30초 재시도, 실패하면 오프라인 표시로 전환되고 **개인 세션은 그대로 계속됩니다.**

```text
익명 로그인 → create_room / join_room RPC (RLS)
→ Realtime Presence(준비·집중·자리비움) + Broadcast(회복·스트레칭·완료·응원)
→ 보스 HP 는 DB 가 최종 기준 (RPC · event_id 중복 차단) + 3초 폴링 보정
→ 연결 끊김 → 30초 재시도 → 실패 시 혼자 모드
```

백엔드는 `supabase/schema.sql` 로 구성합니다 (RLS + RPC, Anonymous Sign-Ins 필요).

## 10. 개인정보 처리 원칙

- 모든 영상 분석은 **브라우저 안에서만** 수행합니다.
- 카메라 영상·사진·프레임·랜드마크 원본을 **저장하지도, 전송하지도 않습니다.** 각 프레임은 즉시 폐기됩니다.
- 로컬에는 개인 기준 **요약값**(특징별 median · MAD · 표본 수)과 세션 집계만 저장합니다.
- 카메라 deviceId 는 복원 불가능한 짧은 해시로만 저장합니다.
- 친구 방에는 **닉네임 · 진행 상태 · 성공 이벤트**만 전송합니다.
  자세 좌표 · `bad` 상태 · 나쁜 자세 시간 · 개인 기준은 전송 금지이며 `sanitizeRoomEvent()` 가 허용 스키마 밖 payload 를 코드 레벨에서 차단합니다.
- 설정 화면의 **전체 데이터 초기화**로 이 브라우저의 모든 기록을 첫 방문 상태로 되돌릴 수 있습니다.
- 의료 진단·치료를 제공하지 않으며, 불편이 지속되면 전문가 상담을 권합니다.
- API secret key · service role key 를 코드나 문서에 넣지 않습니다.

## 14. 현재 알려진 한계

1. **실카메라 임계값 튜닝 미완** — tolerance 바닥값과 yaw 0.7 은 합성 데이터 기준입니다. 실기기·실조명에서의 오탐/미탐 튜닝이 남아 있습니다.
2. **캐릭터 에셋 부족** — Lv.2 / 4 / 5 / 6 은 `idle` 만 있습니다. warning · slouch · recover · attack 이미지는 Lv.1 · Lv.3 만 존재하고, 나머지는 해당 단계의 idle 로 폴백합니다. 모션 WebM 은 없습니다.
3. **의상 이미지 레이어 없음** — 과잠·백팩은 색 리본과 아이콘 배지로만 표현됩니다.
4. **출석 인정 조건이 문서와 다름** — 기획(FR-013)은 "10분 이상 진행 또는 정상 완료"지만, 구현은 **완주한 세션만** 출석으로 표시합니다. `ATTENDANCE_MIN_MS` 상수는 정의만 되어 있고 사용되지 않습니다.
5. **대시보드 집계 근사값** — 상단 `오늘의 기록 · 집중` 값이 `0:00` 으로 고정되어 있고, 최근 세션 누적 시간은 "완료 세션 수 × 25분" 으로 계산합니다(실제 길이 반영 아님).
6. **스트레칭 건너뛰기 이동 경로** — 건너뛰기·결과 보기가 `/result/demo` 로 이동해 현재 세션 id 를 유지하지 않습니다.
7. **친구 방 결과 화면** — 결과 화면의 보스 체력은 개인 보스만 표시하고 공동 보스 결과를 따로 보여주지 않습니다. `bothCompleted` 최종 필살기는 상수만 있고 미구현입니다.
8. **미사용 플래그** — `VITE_ENABLE_PIP` · `VITE_ENABLE_REALTIME` 는 플래그 객체까지만 연결되어 있고 실제 동작을 게이트하지 않습니다.
9. **Realtime 채널** — `realtime.messages` RLS 정책이 없어 표준(비 private) 채널을 사용합니다. 정책을 추가하면 private 로 전환할 수 있습니다.
10. **의료적 검증 없음** — 모든 임계값은 프로토타입 조정값이며 의료 기준이 아닙니다.

자세한 항목별 상태는 [docs/FEATURE_STATUS.md](docs/FEATURE_STATUS.md) 를 참고하세요.
