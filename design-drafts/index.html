다섯 시안이 공통으로 지킨 것
  • 화면과 정보는 현재 셸 그대로입니다 — 탭 다섯, 세션 카드, 방 찾기 세 갈래, 15단계 사다리, 주간 회복, 스트릭과 보호권, 캠퍼스 점유율과 내 기여, 월드의 코인.
  • 캐릭터는 prototypes/openworld/assets/characters 의 실제 스프라이트입니다. 파일 안에 그대로 심어서 인터넷 없이도 뜹니다.
  • 남의 그림·글꼴·로고는 쓰지 않았습니다. 아이콘·창틀·기기·별은 전부 CSS 와 SVG 로 그렸습니다.
  • 1440×900 과 390×844 두 폭에서 확인했습니다. 좁은 폭에서는 각 시안의 뼈대가 그 형태에 맞게 눕습니다(세로 탭 → 가로 줄, 물리 키 → 화면 아래, 스프링 → 위쪽).
  • 캠퍼스 지도는 서울 25개 구를 블록으로 줄인 시안용 그림입니다. 실제 화면은 행정동 423개를 실제 좌표로 그립니다.
