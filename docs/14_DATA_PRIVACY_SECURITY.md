## 5. 익명 인증

- 이메일·전화번호 수집 없음
- 익명 사용자는 Supabase에서 authenticated 역할 사용
- JWT의 사용자 ID로 방 접근을 제한
- 익명 사용자 남용 방지를 위해 rate limit·CAPTCHA를 검토
- 오래된 익명 사용자 정리 정책을 운영 환경에서 검토

### 5.1 캠퍼스 학교 이메일 인증

- 캠퍼스 영토전 참여를 위해서만 Supabase Email OTP를 사용합니다.
- 원본 이메일과 OTP는 Supabase Auth에만 보관합니다. 앱의 public 테이블에는 이메일 주소를 복사하지 않습니다.
- 앱은 인증된 학교 ID, 이메일 도메인, 인증 시각만 저장하며, 선택 학교와 인증 학교가 일치할 때만 서버 RPC가 기여·점령을 허용합니다.
- 인증하지 않은 사용자는 지도·순위를 볼 수 있지만 영토전을 조작할 수 없습니다.

## 6. RLS 원칙

- 모든 방 테이블 RLS 활성화
- room_members에 포함된 사용자만 방 읽기
- 방장 또는 멤버만 제한된 상태 변경
- 클라이언트 damage 직접 덮어쓰기 금지
- 이벤트 payload 서버·클라이언트 양쪽 검증

## 8. 닉네임

- 최대 12자
- HTML escape
- 제어 문자 제거
- 빈 값 기본 닉네임
- 욕설·공격적 표현 필터는 후속 검토
- 실명 입력 유도 없음
