## D-015 AI 세션 회고

- 결정: 사용자가 요청한 한 번의 결과 화면 회고만 제공한다.
- 입력: 비식별 세션 집계 8개만 Gemini 서버 함수로 전송한다.
- 제외: 카메라 원본·스냅샷·좌표·자세 상태·나쁜 자세 지속 시간·목표 문구·식별자·건강 정보.
- 출력: 의료 판단이 아닌 집중 루틴 회고, 3개 하이라이트, 1~5분 다음 행동.
- 관찰: Langfuse에는 원문 없이 모델·스키마·성공 여부·지연 시간만 남긴다.
- 품질: Zod 이중 검증과 Promptfoo 고정 집계 케이스 회귀 평가를 사용한다.
