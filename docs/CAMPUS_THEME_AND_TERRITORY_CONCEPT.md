## 0. 왜 이걸 검토하나

현재 UpRight Now 의 사회적 기능은 **2인 친구 방** 하나입니다.
친구가 없거나 시간이 안 맞으면 혼자 쓰게 되고, 재사용 동기가 캐릭터 성장에만 걸립니다.

캠퍼스 확장의 가설:

> 대학생은 **학교 소속감**이라는 이미 존재하는 정체성을 갖고 있다.
> 그 정체성을 제품 안에 시각적으로(테마·과잠) 그리고 게임적으로(협동전·영토전) 연결하면
> 친구 약속 없이도 "내가 지금 세션을 하면 우리 학교에 보탬이 된다"는 이유가 생긴다.

**검증되지 않은 가설입니다.** 이 문서는 그 가설을 실행 가능한 형태로 적어 두는 것이 목적입니다.

### 절대 흔들리지 않는 전제

| # | 전제 | 이유 |
|---|---|---|
| P-1 | **개인 자세 점수를 어떤 형태로도 노출하지 않는다** | 제품 정체성. 경쟁 지표는 `완료 세션 수` 와 `회복 성공 횟수` 뿐 |
| P-2 | **카메라·자세 데이터를 서버로 보내지 않는다** | 개인정보 원칙 |
| P-3 | **실제 학교 공식 로고·마스코트를 쓰지 않는다** | 상표권 |
| P-4 | **자유 채팅을 만들지 않는다** | 운영 부담·유해성 |
| P-5 | **이건 비공식 서비스다** | 학교와 무관함을 화면에서 명시 |
| P-6 | 자세 관리 품질이 흔들리면 **전부 뒤로 미룬다** | 게임은 2순위 |

## 1. 🎓 학교 선택

### 흐름

```text
설정 또는 온보딩 마지막 단계
→ "다니는 학교가 있나요? (선택)"
→ 검색으로 목록에서 고르기 / 건너뛰기
→ 선택하면 테마·배지·소속이 함께 켜짐
```

### 규칙

| 항목 | 결정 |
|---|---|
| 필수 여부 | **선택**. 건너뛰어도 전 기능 사용 가능 |
| 입력 방식 | 자유 입력 금지 → **미리 준비한 목록에서만 선택** (오타·장난 소속 방지) |
| 변경 | 가능. 단 **쿨다운 30일** (영토전 갈아타기 방지) |
| 소속 없음 | `무소속` — 개인 기능은 100% 동일, 캠퍼스 랭킹에만 미참여 |
| 표시 문구 | 화면 어딘가에 항상 "학교와 무관한 비공식 서비스입니다" |

### 학교 목록 초기 범위

- 1차: 국내 4년제 대학 (교육부 공개 학교 목록 기반, 약 200개)
- 2차 확장 후보: 전문대 · 대학원 · 해외 대학
- 데이터: 학교 **이름 + 지역 + 대표 색 2개**만 보유. 로고·마스코트·주소는 보유하지 않음

## 2. 🎨 상징색 기반 테마

### 원칙

학교의 **분위기**를 재해석합니다. 공식 색상 코드를 그대로 쓰지 않고,
UpRight Now 팔레트(아이보리 배경 60% · 파스텔 포인트 10%) 안으로 **매핑**합니다.

```text
학교 대표색 (예: 진한 남색)
→ 채도·명도를 제품 파스텔 범위로 보정
→ accent-primary / accent-soft 두 토큰으로 축소
→ 기존 pink/yellow/blue/green 역할 토큰 중 "포인트" 자리만 교체
```

### 바뀌는 것 / 안 바뀌는 것

| ✅ 학교 색이 적용되는 곳 | ❌ 절대 바뀌지 않는 곳 |
|---|---|
| 히어로 카드 배경 톤 | 아이보리 배경 (가독성) |
| 사이드바 선택 표시 | 🟢 편안함 = 초록 |
| 학교 배지 · 프로필 칩 | 🟡 변화 감지 = 노랑 |
| 결과 공유 카드 배경 | 🔴 회복 기회 = 코랄 |
| 캠퍼스 화면 강조색 | ⚪ 자리 비움 · 측정 어려움 = 중립 |

**자세 상태 색은 절대 학교 색으로 덮지 않습니다.** 상태 인지가 최우선입니다.

### 접근성 가드

- 매핑 후 배경 대비가 기준 미달이면 **자동으로 톤을 낮춥니다.**
- 색만으로 소속을 전달하지 않고 **학교 이름 텍스트**를 항상 함께 표시합니다.
- 학교 색을 끄는 옵션(`기본 테마 사용`)을 설정에 둡니다.

## 3. 🎖️ 프로필 학교 배지

| 항목 | 내용 |
|---|---|
| 표시 위치 | 사이드바 사용자 요약 · 친구 방 참가자 카드 · 결과 공유 카드 |
| 구성 | 학교 색 원형 + 학교 이름 텍스트 (+ 인증 시 작은 체크) |
| 로고 | **사용 안 함** (P-3) |
| 미인증 표시 | 인증 전에는 배지 옆에 `자기선언` 같은 중립적 라벨 또는 체크 없음 |
| 친구 방 노출 | 닉네임과 같은 수준의 정보로 취급 |

> 학교 배지는 **소속 표현**이지 신원 증명이 아닙니다. 학과·학번·이름은 다루지 않습니다.

## 4. 👕 과잠 · 백팩

현재 상점에는 색상 기반 과잠 4종(네이비·버건디·포레스트·코랄)이 있습니다.
캠퍼스 확장에서는 여기에 **학교 색 과잠**을 추가합니다.

| 종류 | 잠금 조건 | 비고 |
|---|---|---|
| 기본 색상 과잠 4종 | 첫 완주 (현행) | 유지 |
| **학교 색 과잠** | 학교 선택 + 완주 N회 | 색만 학교 색으로 매핑. **문구·로고 없음** |
| **학교 색 백팩** | 학교 선택 + 잎사귀 | 동일 |
| 시즌 한정 과잠 | 시험기간 시즌 참여 | 시즌 종료 후에도 보유 유지 |

**제작 전제**: 이 항목은 [`ROADMAP.md`](./ROADMAP.md) X-2(실제 의상 이미지 레이어)가 **먼저** 끝나야 의미가 있습니다.
지금처럼 색 리본으로 표시되는 상태에서는 "학교 색 과잠"이 그냥 다른 색 리본일 뿐입니다.

## 5. 📤 결과 공유 카드

세션 결과를 이미지 한 장으로 저장·공유합니다.

### 담는 것 / 안 담는 것

| ✅ 담는다 | ❌ 절대 안 담는다 |
|---|---|
| 캐릭터 (현재 단계 + 장착 아이템) | 평균 자세 점수 · 등급 |
| 완료 세션 시간 (예: 25분) | 나쁜 자세 지속 시간 |
| 회복 성공 횟수 | 자세 좌표 · 감지 실패 시간 |
| 캐릭터 단계 이름 | 카메라 영상·캡처 |
| 학교 배지 (선택 시) | 실명 · 학과 · 학번 |
| 과목·목표 (사용자가 켠 경우만) | 위치 정보 |

### 규칙

- 기본은 **비공개**. 사용자가 직접 `카드 만들기` 를 눌러야 생성됩니다.
- 과목·목표 포함 여부를 **생성 직전에 다시 묻습니다** (기본 꺼짐).
- 생성은 브라우저 안에서 canvas 로 처리하고 **서버에 업로드하지 않습니다.**
- 카드 하단에 "학교와 무관한 비공식 서비스" 문구를 넣습니다.

## 6. 📚 시험기간 · 도서관 배경

세션 화면과 대시보드의 **배경 분위기**만 바꾸는 가벼운 연출입니다. 게임 수치에 영향을 주지 않습니다.

| 배경 | 조건 | 분위기 |
|---|---|---|
| 기본 | 항상 | 아이보리 · 식물 소품 |
| **도서관** | 학습 프로필 `도서관` 선택 시 | 책장 실루엣 · 낮은 채도 · 창가 빛 |
| **시험기간** | 시즌 기간 또는 사용자가 직접 켜기 | 포스트잇 · 커피 · 살짝 높아진 대비 |
| 캠퍼스 잔디 | 학교 선택 시 (선택) | 학교 색이 은은하게 깔린 야외 |

### 가드

- 배경은 **캐릭터와 자세 문구의 가독성을 절대 해치지 않습니다.** 대비 검사 후 자동 흐리기.
- 세션 중에는 배경 애니메이션을 넣지 않습니다(반복 흔들림 금지 원칙).
- `prefers-reduced-motion` 에서는 정지 이미지만 사용합니다.
- 배경 끄기 옵션을 설정에 둡니다.
- 시험기간 배경이 **불안을 자극하지 않도록** 합니다. D-DAY 카운트다운·빨간 경고 금지.

## 7. 🗺️ 비공식 캠퍼스 영토전

### 한 줄 정의

> 같은 학교 사용자들의 **완료 세션과 회복 성공**이 모여 자체 지도의 타일을 물들이고,
> 학교끼리 타일을 주고받는 **비공식** 시즌 경쟁.

### 왜 "비공식"인가

- 실제 대학 캠퍼스 지도·건물·로고를 쓰지 않습니다.
- 학교와 어떤 제휴도 없습니다. 화면에 항상 명시합니다.
- 순위는 **학교의 우열이 아니라** 그 시즌 참여자들의 활동량입니다.

### 기여 지표 — 개인 자세 점수 대신 무엇을 쓰나

**P-1 원칙에 따라 자세 점수는 절대 쓰지 않습니다.**

| 행동 | 기여 포인트(초안) | 이유 |
|---|---:|---|
| 세션 **완주** | 10 | 가장 명확한 노력. 자세와 무관하게 누구나 달성 가능 |
| **회복 성공** (세션당 최대 5회) | 2 | 이미 XP 상한이 걸려 있어 그대로 재사용 |
| 스트레칭 완료 (하루 최대 3회) | 1 | 소소한 참여 유도 |
| 친구 방 완주 | +5 보너스 | 함께하기 장려 |

**의도적으로 배제한 지표**

- ❌ 자세 유지 시간·비율 → 자세 좋은 사람이 유리해지면 P-1 위반
- ❌ 감지 가능 시간 → 카메라 좋은 기기가 유리
- ❌ 연속 출석 스트릭 → 처벌형 압박
- ❌ 하루 총 학습 시간 → 과도한 착석을 조장 (제품 목적과 정반대)

> 🚨 **중요**: 이 게임은 "오래 앉아 있기 대회"가 되면 안 됩니다.
> 그래서 지표를 **세션 수**로 두고, 하루 기여 상한(§10)을 반드시 둡니다.

## 8. 🔲 자체 타일 지도

### 형태

실제 지도가 아닌 **추상 타일 보드**입니다.

```text
┌───┬───┬───┬───┬───┬───┐
│ A1│ A2│ A3│ A4│ A5│ A6│      · 육각 또는 사각 타일
├───┼───┼───┼───┼───┼───┤      · 시즌당 고정 개수 (예: 60~120칸)
│ B1│ B2│ B3│ B4│ B5│ B6│      · 각 타일은 "현재 점유 학교" 1곳
├───┼───┼───┼───┼───┼───┤      · 타일마다 누적 기여 게이지
│ C1│ C2│ C3│ C4│ C5│ C6│      · 실제 지리와 무관 (추상 보드)
└───┴───┴───┴───┴───┴───┘
```

### 점유 규칙 (초안)

| 상황 | 처리 |
|---|---|
| 빈 타일 | 기여 포인트를 먼저 임계치까지 채운 학교가 점유 |
| 점유된 타일 | 다른 학교가 **현재 점유 게이지를 넘어서면** 교체 |
| 인접 규칙 | 이미 점유한 타일과 **인접한 타일만** 공략 가능 (무작위 확산 방지) |
| 시작 타일 | 학교가 시즌에 처음 참여하면 빈 타일 1칸을 시작점으로 배정 |
| 감쇠 | 타일 게이지는 하루마다 일정 비율 감소 (방치하면 되돌아옴) |
| 시즌 종료 | 점유 타일 수로 결과 표시. **다음 시즌은 초기화** |

### 표시하지 않는 것

- 개인 사용자가 어느 타일에 얼마나 기여했는지 **타인에게 공개하지 않습니다.**
  (본인 화면에서 "내가 이번 시즌 우리 학교에 N 기여" 정도만)
- 학교별 사용자 수를 직접 노출하지 않습니다(규모 추정 → 비교 압박).

## 9. ⚡ 실시간 영토 변화

| 항목 | 초안 |
|---|---|
| 갱신 주기 | **1~5분 단위 집계** (실시간 초 단위 아님) |
| 전달 방식 | 지도 화면을 열었을 때 폴링 + 열려 있는 동안만 구독 |
| 연출 | 타일 색이 부드럽게 전환 · 방금 바뀐 타일에 짧은 하이라이트 |
| 알림 | 푸시 알림 없음. 앱을 열었을 때 "시즌 소식" 요약 카드로만 |
| 세션 중 | **세션 화면에는 표시하지 않습니다.** 집중을 방해하면 안 됨 |

### 왜 초 단위 실시간이 아닌가

1. 집중 세션 중에 영토가 바뀌는 걸 보면 **공부가 아니라 게임을 하게** 됩니다.
2. 서버 비용과 구현 복잡도가 급격히 올라갑니다.
3. 자세 관리 제품의 톤(조용함)과 맞지 않습니다.

## 10. ⚖️ 학교 규모 보정

**문제**: 재학생 3만 명 학교와 3천 명 학교가 그대로 경쟁하면 결과가 뻔합니다.

### 보정안 3가지 (택일 필요 — §14 Q3)

| 안 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A. 활성 사용자 기준 정규화** | `기여 총합 ÷ 그 시즌 활성 사용자 수` | 규모 무관, 계산 단순 | 소수 정예 학교가 유리. 사용자 수 노출 위험 |
| **B. 참여자 상한** | 학교당 시즌 기여 인원을 상위 N명(예: 50명)까지만 집계 | 큰 학교의 물량 우위 차단 | 늦게 참여한 사람의 기여가 무시됨 |
| **C. 로그 스케일 가중** | `유효기여 = 기여총합 ÷ log₂(활성자수 + 1)` | 규모 우위를 줄이되 완전히 지우지 않음 | 사용자가 이해하기 어려움 |

**초기 권장**: **B + 개인 상한 조합**

```text
개인 하루 기여 상한:  40 포인트 (세션 4회 정도)
학교 시즌 집계 인원:  상위 50명
학교 하루 기여 상한:  1,000 포인트
```

이유: 이해하기 쉽고, 활성 사용자 수를 **공개하지 않아도** 되며, 과도한 착석을 막습니다.

### 리그 분리 (보완)

규모 보정만으로 부족하면 **활성 사용자 수 구간별 리그**로 나눕니다.
단, 리그 구간을 공개하면 학교 규모가 드러나므로 **리그 이름을 중립적으로**(예: 숲 · 언덕 · 호수) 짓습니다.

## 11. 🛡️ 익명 사용자의 악용 방지

현재 친구 방은 **Supabase 익명 인증**을 씁니다. 영토전에 그대로 쓰면 다계정 문제가 생깁니다.

### 위협과 대응

| 위협 | 대응 |
|---|---|
| 시크릿 창으로 계정 대량 생성 | **인증 전 사용자는 영토전 기여 불가** (§12 참고) |
| 세션을 시작하자마자 종료 반복 | 기여는 **완주(80% 이상)** 만 인정. 3분 데모는 기여 0 |
| 데모/QA 값으로 기여 | 데모 세션은 서버에 보고하지 않음 (현재도 로컬 저장 안 함) |
| 시간을 조작한 클라이언트 | 기여 보고는 **서버 시각**으로 기록. 세션 시작·종료 시각을 서버가 검증 |
| 한 사람이 여러 학교 갈아타기 | 학교 변경 **쿨다운 30일**, 변경 시 이전 학교 기여는 이전 |
| 봇으로 세션 자동 완주 | 세션당 최소 실제 경과 시간 검증 + 하루 상한 + 이상 패턴 계정 시즌 제외 |
| 특정 학교 좌표 폭격 | 인접 타일만 공략 가능 + 하루 학교 상한 |
| 신고·조작 대응 | 시즌 종료 후 **수동 검토 기간**(예: 3일)을 두고 결과 확정 |

### 서버가 반드시 검증할 것

- 기여 이벤트는 **RPC 로만** 적립하고 event_id 로 중복 차단 (친구 방과 동일 패턴)
- 클라이언트가 보낸 포인트 값을 믿지 않고 **서버가 이벤트 종류로 환산**
- 세션 완주 보고에 `started_at` / `ended_at` 포함, 서버가 최소 지속 시간 검증
- 계정당 하루 상한 · 학교당 하루 상한을 **DB 제약과 함수 안에서** 강제

## 12. 🎫 대학 인증 전 · 후 단계

### 2단계 모델

| 단계 | 이름 | 어떻게 | 할 수 있는 것 | 할 수 없는 것 |
|---|---|---|---|---|
| **1단계** | 자기선언 | 목록에서 학교 선택만 | 테마 · 학교 배지(체크 없음) · 학교 색 과잠 · 결과 공유 카드 | **영토전·협동전 기여** |
| **2단계** | 인증됨 | 학교 이메일 확인 링크 | 1단계 전부 + 배지에 체크 + **영토전·협동전 기여** | — |

### 인증 방식 (초안)

```text
설정 → 학교 인증
→ 학교 메일 주소 입력 (@university.ac.kr 형태만 허용)
→ 확인 링크 발송
→ 링크 클릭 시 "인증됨" 플래그만 저장
```

### 개인정보 최소 수집

| 저장한다 | 저장하지 않는다 |
|---|---|
| 학교 id | **이메일 주소 원문** |
| 인증 여부 (boolean) | 이름 · 학번 · 학과 |
| 인증 시각 | 재학 여부 · 졸업 여부 |
| 이메일 도메인의 **해시** (중복 인증 방지용) | 메일 본문·수신 이력 |

- 인증 메일 발송은 외부 메일 서비스를 쓰되, **주소를 저장하지 않고 발송 직후 폐기**합니다.
- 도메인 해시만 남겨 "이 주소로 이미 인증했는가"만 확인합니다.
- 인증은 **선택**입니다. 인증하지 않아도 개인 기능은 100% 동일합니다.
- 졸업생·휴학생 처리는 하지 않습니다(재학 여부를 판단하지 않음).

> ⚠️ 이메일 인증은 개인정보 처리 범위를 넓힙니다.
> **처리방침 갱신과 동의 흐름이 반드시 함께 설계되어야 합니다.**

## 13. 🗄️ Supabase 데이터 구조 초안

> 초안입니다. 실제 적용 전 RLS·인덱스·rate limit 을 다시 검토합니다.
> 기존 `supabase/schema.sql` 은 건드리지 않고 **별도 마이그레이션**으로 추가합니다.

### 13.1 테이블

```sql
-- 학교 목록 (읽기 전용 마스터)
schools
  id              uuid pk
  name            text not null unique      -- 표시 이름
  region          text                      -- 지역 (리그 참고용)
  color_primary   text                      -- 제품 팔레트로 매핑된 색 (원본 공식색 아님)
  color_soft      text
  email_domains   text[]                    -- 인증 허용 도메인 목록
  is_active       boolean default true
  -- 로고·마스코트·주소 컬럼은 두지 않는다 (P-3)

-- 사용자 소속 (익명 사용자 1행)
user_school
  user_id         uuid pk references auth.users
  school_id       uuid references schools
  verified        boolean default false     -- 2단계 인증 여부
  verified_at     timestamptz
  email_domain_hash text                    -- 이메일 원문 저장 금지
  changed_at      timestamptz               -- 학교 변경 쿨다운 계산용
  created_at      timestamptz default now()

-- 시즌
seasons
  id              uuid pk
  name            text
  starts_at       timestamptz
  ends_at         timestamptz
  board_width     int                       -- 타일 보드 크기
  board_height    int
  status          text check (status in ('upcoming','running','review','closed'))

-- 타일 상태
season_tiles
  season_id       uuid references seasons
  tile_x          int
  tile_y          int
  owner_school_id uuid references schools    -- null = 빈 타일
  gauge           int default 0 check (gauge >= 0)
  updated_at      timestamptz default now()
  primary key (season_id, tile_x, tile_y)

-- 기여 이벤트 (중복 차단 · 감사 로그)
season_contributions
  event_id        uuid pk                    -- 클라이언트 생성, 중복 차단
  season_id       uuid references seasons
  user_id         uuid references auth.users
  school_id       uuid references schools
  kind            text check (kind in ('session_completed','recovery','stretch','room_completed'))
  points          int not null               -- 서버가 kind 로 환산한 값
  tile_x          int
  tile_y          int
  created_at      timestamptz default now()
  -- 자세 좌표·상태·지속 시간 컬럼은 절대 두지 않는다 (P-2)

-- 일일 상한 집계 (빠른 검사용)
season_daily_caps
  season_id       uuid
  day             date
  user_id         uuid
  school_id       uuid
  user_points     int default 0
  primary key (season_id, day, user_id)
```

### 13.2 RPC (초안)

| 함수 | 역할 | 검증 |
|---|---|---|
| `set_user_school(p_school_id)` | 소속 지정·변경 | 30일 쿨다운, 활성 학교인지 |
| `request_school_verification(p_email)` | 인증 메일 요청 | 도메인 허용 목록, **이메일 미저장** |
| `confirm_school_verification(p_token)` | 인증 확정 | 토큰 유효성, 도메인 해시 중복 |
| `contribute(p_event_id, p_kind, p_tile_x, p_tile_y, p_started_at, p_ended_at)` | 기여 적립 | ① 인증 여부 ② event_id 중복 ③ **서버가 kind→points 환산** ④ 개인/학교 일일 상한 ⑤ 최소 세션 지속 시간 ⑥ 인접 타일 여부 |
| `get_board(p_season_id)` | 보드 조회 | 공개 읽기 (집계 결과만) |

### 13.3 RLS 방향

| 테이블 | 읽기 | 쓰기 |
|---|---|---|
| `schools` | 모든 인증 사용자 | 없음 (관리자 전용) |
| `user_school` | 본인 행만 | RPC 만 |
| `seasons` | 모든 인증 사용자 | 없음 |
| `season_tiles` | 모든 인증 사용자 (집계 결과) | RPC 만 |
| `season_contributions` | **본인 행만** | RPC 만 |
| `season_daily_caps` | 본인 행만 | RPC 만 |

- 타인의 기여 내역은 **어떤 경로로도 조회할 수 없습니다.**
- 보드는 학교 단위 집계 결과만 노출하고 개인 기여를 역산할 수 없게 합니다.

### 13.4 클라이언트가 보내지 않는 것 (재확인)

카메라 영상 · 프레임 · 랜드마크 · 자세 좌표 · `bad` 상태 · 나쁜 자세 시간 ·
개인 자세 기준 · 감지 품질 · 민감도 설정

## 15. 🪜 구현 단계

각 단계는 **이전 단계 없이 시작하지 않습니다.** 앞 단계만으로도 사용자 가치가 있어야 합니다.

| 단계 | 범위 | 사용자에게 주는 가치 | 선행 조건 |
|---|---|---|---|
| **C-0** | 자세 관리 품질 확보 | — | [`ROADMAP.md`](./ROADMAP.md) Now 전 항목 완료 |
| **C-1** | 학교 선택 + 테마 + 배지 | "내 학교 색으로 쓰는 앱" | 학교 목록 데이터 · 색 매핑 규칙 · C-0 |
| **C-2** | 학교 색 과잠·백팩 | 소속감 있는 캐릭터 꾸미기 | 의상 이미지 레이어(X-2) · C-1 |
| **C-3** | 결과 공유 카드 | 혼자서도 자랑할 것이 생김 | C-1 (서버 불필요) |
| **C-4** | 시험기간·도서관 배경 | 계절감 · 몰입 | 배경 에셋 · C-1 |
| **C-5** | 학교 인증 (2단계) | 신뢰 가능한 소속 | 개인정보 처리방침 갱신 · 메일 발송 인프라 |
| **C-6** | 캠퍼스 협동전 (지도 없음) | "우리 학교 사람들과 하나의 보스" | C-5 · 기여 RPC · 상한 시스템 |
| **C-7** | 영토전 (타일 보드) | 학교 간 시즌 경쟁 | C-6 검증 완료 · 규모 보정 확정 |
| **C-8** | 시즌 운영 (결과·초기화·검토) | 반복되는 시즌 | C-7 |

**C-6 를 C-7 보다 먼저 두는 이유**: 협동전은 학교 간 비교가 없어 규모 보정·악용 방지 부담이 훨씬 작습니다.
협동전에서 기여 시스템과 상한이 실제로 작동하는지 확인한 뒤에 영토전으로 확장합니다.

### 검증 게이트

| 게이트 | 통과 조건 |
|---|---|
| C-1 → C-2 | 학교 테마에서 **자세 상태 색이 한 번도 가려지지 않음** (대비 검사 통과) |
| C-5 → C-6 | 개인정보 처리방침 갱신 + 동의 흐름 검수 완료 |
| C-6 → C-7 | 다계정 시도 · 하루 상한 우회 시도가 서버에서 전부 차단됨 |
| C-7 → C-8 | 최소 3개 학교 · 각 10명 이상 참여로 한 시즌 완주 |
