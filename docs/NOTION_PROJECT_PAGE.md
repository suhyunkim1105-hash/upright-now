## 🌱 서비스 개요

UpRight Now 는 자세를 **점수로 평가하지 않습니다.**
대신 사용자가 직접 등록한 "이 자리에서 편안한 자세"를 기준으로 삼고,
그 기준에서 벗어났다가 **다시 돌아온 행동**만 보상합니다.

```text
편안한 자세 5초 등록
→ 기준에서 벗어남 (5초 지속)
→ 회복 기회 (30초)
→ 기준으로 돌아와 5초 유지
→ 마감괴수 특수 공격 + 경험치 + 잎사귀
→ 거북이가 기린으로 성장
```

게임 버튼을 따로 누르지 않습니다. **실제 회복 행동만이 게임을 진행시킵니다.**
게임을 전부 걷어내도 자세 관리 기능은 그대로 성립하도록 설계했습니다.

## 🔥 문제 정의

대학생은 시험·과제·코딩에 몰입할수록 머리와 상체가 **자신의 편안한 기준에서 벗어난 사실을 늦게** 알아차립니다. 불편해진 뒤에야 자세를 고칩니다.

기존 도구가 실패하는 지점:

| 문제 | 사용자에게 생기는 결과 |
|---|---|
| 반복 경고·강제 팝업 | 기능을 꺼 버리거나 서비스를 이탈 |
| 획일적인 자세 점수 | 의료적 정상·비정상으로 오해 |
| 장소·카메라 높이 변화 | 잘못된 알림 → 신뢰 하락 |
| 혼자 쓰는 자세 도구 | 다시 켤 동기 부족 |
| 공부 게임과 자세 기능의 분리 | 이도 저도 아닌 경험 |
| 카메라 사용 | 영상 저장·전송에 대한 불안 |

**우리의 답**: 점수가 아니라 **회복 행동**을 보상한다. 흐트러짐을 지적하는 대신, 돌아온 순간을 즉시 축하한다.

## 🏫 왜 대학생인가

| 근거 | 내용 | 주의 |
|---|---|---|
| 시험기간 착석 시간 증가 | 학기 중 대비 시험기간에 앉아 있는 시간이 늘고 신체활동이 줄며 목·등·허리 불편 보고가 증가하는 연구 결과 | 자세가 통증의 **직접 원인이라는 뜻은 아님** |
| 노트북·태블릿 사용 | 대학생 단면 조사에서 구부정한 앉은 자세와 노트북 사용이 목 불편 보고와 **연관**되어 나타남 | 단면 연구이며 **인과·진단 근거 아님** |
| 흐름을 깨는 휴식에 대한 거부감 | 재택 학습 질적 연구에서 일부 학생이 몸이 불편해진 뒤에야 오래 앉았음을 인지하고, 자리를 뜨는 휴식이 흐름을 방해한다고 느낌 | → 강제 팝업 대신 **주변부 피드백** |
| 짧은 휴식의 효과 | 마이크로 브레이크 메타분석에서 활력·피로에 작지만 긍정적 효과. 전체 성과 향상은 불명확 | → `집중력 향상` 이 아니라 **`짧은 리셋`** 으로 표현 |
| 방해가 적은 알림 | 은은한 시각 신호가 강한 즉시 경고보다 과제 방해를 줄이면서 자세 변화를 유도할 가능성 | → 캐릭터·주변부 색 우선, 소리는 선택 |

**추가로 대학생이 맞는 이유 (제품 관점)**

- 장소를 자주 옮겨 다녀 **"장소별 개인 기준"** 이라는 접근이 실제로 필요합니다.
- 과잠·백팩·팀플·시험기간처럼 **공유 가능한 문화 코드**가 뚜렷해 아이템·테마 설계가 쉽습니다.
- 2인 팀플 문화가 있어 **자유 채팅 없이도** 함께하는 세션이 자연스럽습니다.

> ⚠️ 아래는 **검증되지 않은 가설**입니다: 6단계 캐릭터가 재사용을 높인다 · 2인 방이 완주율을 높인다 · 과잠·백팩이 대학생 정체성을 강화한다 · 회복 공격이 경고 피로를 줄인다.

## 🚶 핵심 사용자 여정

### 첫 방문 (약 1분)

```text
① 대시보드         "오늘의 목표, 편안한 자세로 시작해 볼까요?"
② 닉네임           최대 12자 · 미입력 시 "익명의 기린"
③ 학습 프로필      도서관 · 내 공간 · 팀플
④ 카메라 안내      권한창은 버튼을 누른 뒤에만 열림
⑤ 5초 기준 등록    얼굴 + 양쪽 어깨가 보이게 편안히 앉기
⑥ 세션 설정        과목 · 목표 · 길이 · 혼자/친구
⑦ 집중 세션        캐릭터 · 남은 시간 · 마감괴수
⑧ 2분 리셋         스트레칭 (건너뛰기 가능)
⑨ 결과             회복 성공 · 감지 가능 시간 · 획득 XP · 목표 진행도
```

카메라가 없어도 **3분 데모**로 전 흐름을 볼 수 있습니다.

### 세션 안에서 반복되는 루프

```text
편안함(good)
  └→ 조금 달라짐(warning, 1.5초)
        └→ 기준에서 벗어남(bad, 5초 지속)
              └→ 🎯 회복 기회 (30초 창)
                    ├→ 기준 복귀 후 5초 유지 → ✨ 회복 성공 → 특수 공격 + XP
                    └→ 30초 초과 → 이번 기회 종료 (벌점 없음, 콤보만 0)
              └→ 20초 냉각 후 다시 감지
```

## 📐 개인 자세 기준

### 원칙

- **개인 기준 대비 상대 변화**만 판정합니다. 절대 각도·의료 기준을 쓰지 않습니다.
- 모든 값은 **어깨 너비로 정규화**합니다. 고정 픽셀값을 쓰지 않습니다.
- **한 프레임으로 상태를 바꾸지 않습니다.** 모든 전이가 지속 시간을 요구합니다.
- 자세나 시선으로 **집중 여부를 추론하지 않습니다.**

### 캘리브레이션 (5초)

| 항목 | 값 |
|---|---|
| 목표 시간 | 5초 (앞 1초는 모델 예열로 제외) |
| 최소 유효 표본 | 40 프레임 |
| 실패 판정 | 12초 안에 표본 미달 → 자동 재시작 |
| 저장 값 | 특징별 **중앙값 + MAD + 표본 수** (평균 아님, 원본 없음) |

나쁜 프레임(움직임·회전·어깨 누락)은 **그 프레임만** 버리고 전체를 초기화하지 않습니다.

### 보는 것 6가지

| 특징 | 의미 | 구분 |
|---|---|---|
| 얼굴 크기 비율 | 카메라 쪽으로 접근 | 주 |
| 눈–어깨 세로 거리 | 고개 숙임 · 움츠림 | 주 |
| 코의 좌우 치우침 | 좌우 기울기 | 주 |
| 어깨 높이 차 | 한쪽으로 기울기 | 주 |
| 상체 좌우 쏠림 | 엉덩이가 보일 때만 | 주 |
| 앞뒤 깊이(z) | 앞으로 나옴 | **보조 — 단독으로 경고를 만들지 않음** |

### 자세 상태 5종

| 상태 | 화면 문구 | 확정에 걸리는 시간 |
|---|---|---|
| 🟢 편안함 | 편안한 기준에 가까워요. | 2초 |
| 🟡 변화 감지 | 자세가 조금 달라지고 있어요. | 1.5초 |
| 🔴 회복 기회 | 처음 등록한 기준으로 가볍게 돌아와 볼까요? | **5초** |
| ⚪ 자리 비움 | 잠시 자리를 비웠어요. 돌아오면 측정을 이어갈게요. | 연속 8프레임 미감지 |
| ⚠️ 측정 어려움 | 측정하기 어려운 상태예요. 카메라 위치와 조명을 확인해 주세요. | 즉시 |

- 감지 품질은 별도로 `좋음 / 불안정 / 불가` 로 표시합니다.
- 귀·엉덩이가 안 보여도 **측정을 계속합니다**(불안정으로 표시).
- `자리 비움`·`측정 어려움` 에서는 회복 타이머가 **동결**됩니다. 실패로 처리하지 않습니다.
- 민감도 3단계(부드럽게 ×1.4 / 기본 ×1.0 / 민감하게 ×0.75)로 허용 범위를 조절합니다.

> 모든 임계값은 **프로토타입 조정값이며 의료 기준이 아닙니다.**

## 🎮 게임 시스템

### 마감괴수 D-DAY

| | 혼자 | 친구 방 |
|---|---:|---:|
| 최대 체력 | 1000 | 2000 |

| 체력 | 상태 라벨 |
|---|---|
| 60% 초과 | 과제지를 쌓는 중 |
| 30~60% | 포스트잇을 뿌리는 중 |
| 30% 이하 | 23:59 폭주 |
| 0 | 제출 완료 |

세션 중 보스를 **직접 조작하지 않습니다.** 회복과 완주가 자동으로 공격이 됩니다.

### 행동 → 결과

| 현실 행동 | 게임 결과 | XP | 잎사귀 | 피해 |
|---|---|---:|---:|---:|
| 자세 회복 성공 | ⚡ 특수 공격 | 30 | 10 | 40 |
| 세션 완주 | 🗡️ 기본 공격 | 100 | 100 | 100 |
| 스트레칭 완료 | 🛡️ 방어막 회복 | 20 | 20 | — |
| 목표 완료 자기보고 | 🎁 보너스 상자 | 20 | 20 | — |
| 두 사람의 가까운 회복 | 🦒 기린 싱크 | — | — | 60 (공동) |

### 악용 방지

- XP·잎사귀 적립은 **한 함수만** 통과합니다. 같은 이벤트 id 는 두 번 적용되지 않습니다.
- 회복 보상은 **세션당 최대 5회**까지 적립됩니다(회복 횟수 자체는 계속 기록).
- 세션 종료도 **단일 진입점**이라 중복 종료·중복 보상이 불가능합니다.
- 회복 기회를 놓쳐도 **XP 가 깎이지 않습니다.** 현재 세션 콤보만 0이 됩니다.

| ✅ 공유 | ❌ 공유 안 함 |
|---|---|
| 닉네임 (최대 12자) | 카메라 영상 · 사진 · 프레임 |
| 참가 상태 (준비 / 집중 / 자리 비움 / 완료) | 랜드마크 · 자세 좌표 |
| 캐릭터 성장 단계 | **`나쁜 자세` 상태** |
| 성공 이벤트 (회복 · 스트레칭 · 완주) | 나쁜 자세 지속 시간 |
| 응원 3종 | 개인 자세 기준 · 개인 점수 |

허용 필드 6개 밖의 키가 하나라도 섞이면 **payload 를 통째로 버립니다.** 송신·수신 양쪽에 적용됩니다.

### 공동 보스

| 행동 | 효과 |
|---|---|
| 회복 성공 | HP −40 |
| 세션 완주 | HP −100 |
| 🦒 기린 싱크 | HP −60 |
| 스트레칭 완료 | 방어막 +15 |

- **HP 의 최종 기준은 데이터베이스**입니다. 클라이언트가 덮어쓸 수 없습니다.
- 같은 이벤트가 두 번 반영되지 않도록 서버가 이벤트 id 로 차단합니다.

## 🏗️ 기술 구조

```text
[브라우저]
  카메라 → MediaPipe Pose Landmarker (~12fps, 온디바이스)
         → 랜드마크 분석 (어깨 너비 정규화)
         → 개인 기준 대비 방향성 편차 계산
         → 지속 시간 확정 (arbiter)
         → 자세 상태 머신 (회복 창 · 냉각)
         → 게임 브리지 → 보스 피해 + XP/잎사귀 + 친구 방 이벤트
  로컬 저장: 버전 있는 localStorage (v2)

[서버 — 친구 방에서만]
  Supabase 익명 인증
  → rooms / room_members / room_events_processed (RLS)
  → Realtime Presence + Broadcast
  → 보스 HP 는 원자적 RPC 로만 변경 (이벤트 id 중복 차단)
```

| 영역 | 사용 기술 |
|---|---|
| 앱 | React 19 · Vite 8 · TypeScript 7 (strict) |
| 라우팅 | React Router 7 |
| 상태 | Zustand 5 |
| 스타일 | Tailwind CSS 4 |
| 자세 감지 | `@mediapipe/tasks-vision` Pose Landmarker |
| 로컬 저장 | 버전 있는 localStorage (v2) |
| 친구 방 | Supabase (Auth Anonymous · Realtime · RPC) |
| 테스트 | Vitest · Testing Library · Playwright |
| 배포 | Vercel |

**설계 원칙**

- 시간 임계값은 **상수 파일 한 곳**에서만 관리합니다.
- 상태 전이 로직은 순수 함수로 두어 UI 없이 테스트합니다(시계 없이 delta 로만 계산).

- 보상 무결성 (중복 차단 · 세션당 5회 상한 · 중도 종료 보상 0)
- 저장 (스키마 버전 · 마이그레이션 · 데모 값 미저장 · 전체 초기화)
- 친구 방 (금지 필드 차단 · 기린 싱크 1회 · 두 브라우저 HP 동기화)
- 개인정보 (금지 표현 미노출 · 운영 빌드 QA Lab 비노출)

### 자동 테스트로 확인할 수 없는 것

실제 웹캠·실제 두 사람이 필요합니다 → `docs/QA_CHECKLIST.md`

1. 편안한 자세 30초 동안 오탐 없음
2. 귀 가림 · 엉덩이 화면 밖에서도 측정 지속
3. 숙임 5초 → 회복 기회 → 복귀 5초 → 보상
4. PiP 자동 열림 (Chrome 116+)
5. 두 대의 실기기 친구 방 전 과정
