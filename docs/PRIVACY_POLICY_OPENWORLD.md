# 기린캠퍼스 오픈월드 개인정보처리방침

시행일: 2026년 8월 17일

이 문서는 현재 `prototypes/openworld` 프로토타입의 동작 범위를 설명합니다. 정식 서비스로 배포할 때는 운영 주체, 문의처, 보유기간, 법정 고지사항을 실제 정보로 교체하고 법률 검토를 진행해야 합니다.

## 1. 처리 원칙

기린캠퍼스는 집중 세션에서 웹캠을 사용할 수 있습니다. 웹캠 영상과 자세 분석은 사용자의 브라우저 안에서 처리하며, 현재 오픈월드 프로토타입에는 외부 서버로 보내는 `fetch`, WebSocket, Supabase 연동이 없습니다.

## 2. 처리하는 정보

- 카메라 영상·프레임: 집중 세션 중 브라우저 메모리에서 자세 분석에만 사용
- 얼굴 이미지·프레임별 랜드마크·원본 자세 좌표: 저장·전송하지 않음
- 닉네임, 학교 선택, 코인, 출석, 세션 요약, 캘리브레이션 기준, 설정: 브라우저 `localStorage`에 저장될 수 있음
- 미니게임 진행 상태와 보상: 현재 세션과 브라우저 저장 데이터에서 처리

## 3. 카메라 처리와 삭제

카메라 권한은 사용자가 집중 세션을 시작할 때 요청합니다. 세션이 끝나거나 사용자가 카메라를 끄면 MediaStream 트랙을 중지합니다. 저장된 로컬 데이터는 브라우저의 해당 사이트 데이터 삭제 기능으로 지울 수 있습니다.

## 4. 제3자 제공과 AI 기능

현재 오픈월드 프로토타입은 카메라 영상·자세 좌표를 제3자에게 제공하지 않습니다. 향후 AI 리포트나 멀티플레이 서버를 연결할 경우, 전송 항목·보유기간·동의 절차를 별도로 고지하고 이 정책을 갱신해야 합니다.

## 5. 민감정보와 의료적 해석

이 서비스는 의료 진단·치료 서비스가 아닙니다. 통증, 질환, 건강 상태를 수집하거나 자세를 의료적으로 판정하지 않습니다.

## 6. 이용자 권리와 문의

이용자는 브라우저 저장 데이터의 삭제를 요청하거나 직접 수행할 수 있습니다. 정식 배포 전 운영자는 문의 이메일, 개인정보 보호책임자, 삭제 요청 처리 절차를 이 문서에 추가해야 합니다.

## 7. 변경

서버 저장, 분석 도구, AI 리포트, 멀티플레이 등 데이터 흐름이 추가되면 변경 내용을 고지하고 시행일을 갱신합니다.
