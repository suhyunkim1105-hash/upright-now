## 시작 전 준비

- [ ] Production(https://upright-now.vercel.app) 또는 로컬(`npm run dev`) 중 무엇을 볼지 정합니다.
- [ ] 카메라 항목을 확인하려면 `VITE_ENABLE_CAMERA=true` 여야 합니다.
- [ ] 친구 방 항목을 확인하려면 `VITE_ENABLE_FRIEND_ROOM=true` + Supabase 값 3개가 필요합니다.
- [ ] 깨끗한 상태에서 시작하려면 `/settings` → **모든 데이터 삭제** 를 먼저 실행합니다.
- [ ] 시크릿 창을 쓰면 기존 저장값과 섞이지 않습니다.

**표기**: ✅ 통과 · ⚠️ 애매 · ❌ 실패 — 실패한 항목은 브라우저·조명·자리 조건을 함께 적어 주세요.
