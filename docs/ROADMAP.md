경쟁 지표는 항상 `완료 세션 수` 와 `회복 성공 횟수` 입니다.

| E-2 | **캠퍼스 영토전** | 자체 타일 지도에서 학교끼리 영토를 주고받는 비공식 경쟁 | 익명 사용자 악용 방지, 규모 보정 공식, 실시간 변화 주기 |
