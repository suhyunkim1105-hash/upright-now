## [끝난 것]

### 세계

- 32×48 캐릭터 여덟 종 · 타일 16→32 · 캐릭터가 정확히 1.00 × 1.50 칸
- 기숙사 확장 + 가구, **마우스로 끌어 놓기**(못 놓는 자리는 빨갛게, 우클릭 치우기)
- 지도 확대·축소 — 단추 + 마우스 휠(0.18초 묶음)
- 중앙 표지판 디벨롭 · 도서관/본관 외 세션 자리 삭제 · **친구방 코드 완전 삭제**
- 이미지 튜토리얼 넉 장(전체 + 기숙사). 한 번 보면 안 뜨고 설정에서 다시 보기
- 상호작용 기호 **▼** (`!` 는 RPG 문법상 "새 퀘스트"라 상시 표시엔 안 맞음)
- 명예의 전당 실시간 + 학교 순위(베이즈 축소, C=30 · 하루 240분 상한)

### 상점 (8/19)

- **셋으로 갈랐습니다** — 옷 가게 · 가구 가게 · 알 가게
- 옷·가구는 동아리 거리 천막, 알은 학생회관 미르
- 상점 안내(노란 천막) + 바로 가기 셋
- 왼쪽 세로 탭 막대

### 판정·PIP

- **기준선 대비** 판정(절대 각도 아님). 거북목인 사람이 켜자마자 처지지 않습니다
- PIP 얼굴 여덟 종 × 다섯 상태. 얼굴 하나를 만들고 거기서 다섯으로 나눔
- 캐릭터가 나 대신 무너짐(droop 하나가 머리·몸통·눈꺼풀을 함께)
- 회의 모드 — 알림만 끄고 측정은 유지

### 서버

- Supabase 서버 저장 · 코인은 **서버가 지급**(클라이언트가 금액을 못 보냄)
- 진짜 멀티플레이(Realtime presence/broadcast)
- 욕설 필터(korcen.js) · 채팅 도배 제한

### 병합하다 찾은 것

- 자세 판정이 **한 번도 확정되지 않고 있었습니다**(`POSE.votes` 가 매 프레임 던짐)
- click 리스너가 두 벌 → 기린 목 펴기가 한 번 눌러 두 번 셈
- `scripts/*.test.mjs` 열 개가 **한 번도 안 돌고 있었습니다**(vitest include 가 src/** 뿐)
- 랜딩 리그 엠블럼 다섯 장이 **배포본에서만** 404(경로 고치기가 역따옴표를 못 봄)
- `build-items.mjs` 가 조용히 죽어 있었음
