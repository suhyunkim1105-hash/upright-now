## [왜 3D 로 갔나]

UXI 교수님 지적이 시작이었습니다. "월드맵을 할 거면 3D 로 크게 해야 하고,
기숙사방도 싸이월드처럼 3D 로 했어야 한다. 1인칭도 되어야 하고, 걷는 걸
최소화해야 한다."

처음에는 못 한다고 답할 뻔했습니다. 실제로 해 보니 **3D 가 더 쉬웠습니다.**
이유는 하나입니다 — 아이소메트릭 픽셀아트는 사람이 한 장씩 그려야 하지만
3D 는 형상이 코드입니다. 창 하나를 함수로 만들면 여섯 채가 다 씁니다.

그리고 3D 로 오면서 **옷 문제가 사라졌습니다.**

| | 2D | 3D |
|---|---|---|
| 옷 스프라이트 | 8종 × 아이템 = **207장** | 몸이 같으므로 **19벌** |
| 새 종 추가 | 옷을 전부 다시 자름 | 머리 하나 |
| 새 옷 추가 | 8장 | 1벌 |

## [8/21 밤 — 피드백 반영판]

수현님 피드백을 받아 하루에 갈아엎은 것들입니다.

**보이는 것**
- 캐릭터 여덟 중 일곱을 다시 빚었습니다(개구리만 유지 지시). 눈은 큰 빛점
  하나(개구리 문법)로 통일, 볼터치 공통. 거북이는 등딱지를 **등에 메고**,
  햄스터 볼은 얼굴 폭으로, 고슴도치 가시는 끝이 둥근 머리칼로
- 옷이 **디자인**이 됐습니다 — 상의 4(반팔·후드·셔츠·과잠) · 하의 4 ·
  신발 3 · 모자 3 · 안경 3 · 가방 2, 색 8. id 는 2D 아이템 표와 같아서
  서버 구매(world_buy_item)와 그대로 이어집니다
- 간판이 전부 제 이름을 답니다 — bake 가 텍스처 재질을 합쳐 버려서
  옆 건물 글씨가 잘려 보이던 것('기수')을 굽기에서 제외로 해결
- M 지도와 미니맵이 **실제 3D 씬을 비스듬히 찍은 사진**입니다
- 동상은 면을 줄인 조각으로 재제작, 정문 뒤 숲 제거, 건물에 겹친 나무 제거

**움직임**
- 걸을 때 줌이 들쭉날쭉하던 것 — 카메라 가림 거리를 감쇠로만 따라가게
- 잔디·바닥 번쩍임 — 태양 그림자 카메라를 텍셀 격자에 스냅
- 문·계단 뚫림 — 현관 폭을 막는 충돌 추가
- 세션 시작 화면이 아이보리(가구 속살)로 뜨던 것 — 키 큰 가구 격자를
  따로 두고 앉을 때 빈 방향을 골라 카메라를 세웁니다
- 말 걸면 상대가 멈춰 서서 나를 봅니다. 창은 내가 떠나야 닫힙니다

**기능(2D 패리티)**
- 모든 의자에 앉습니다(방 지을 때 자리 자동 등록). 도서관·본관·기숙사
  의자는 자세 세션, 소파·벤치는 그냥 앉기
- 이름·학교·세션 시간 상단 표시, 학교 10곳 선택(과잠 색 연동)
- 자세 5단계 얼굴(good/warn/bad/recover/sleep)을 눈으로 표현 + 경고음
- 상점 셋 실동작: 옷(서버 값표) · 가구 · 알(3분 부화 → 새 종 해금)
- 기숙사: 가구 놓기(유령 미리보기 · R 회전) · 창밖 날씨(/api/weather) ·
  시간표 · 옷장
- 학식·자판기·인형뽑기 —  코인이 실제로 줄고 뽑은 가구가 남습니다
- 명예의 전당 — world_school_ranking 호출, 서버 없으면 없다고 말합니다
- 세션 종료 → world_finish_session, 코인은 서버 잔액으로 갱신
- 채팅 korcen 욕설 필터 + 1.2초 도배 제한, 미니게임 10코인 하루 1회
- 장소별 앰비언트(WebAudio 합성) — 옷장 설정에서 켜고 끕니다
- 미니게임: 동물 합치기(수박게임 방식, matter-js) 추가
- 들어가고 나올 때 몇 초 얼던 것 — 방 여섯을 로드 직후 미리 지어 둡니다
- 도서관 26×18 로 확장(창가 자리 · 잡지꽂이 · 라운지)

## [속도 — 민철이 잡은 렉과 같은 문제]

이 월드는 **웹캠 자세 추정과 같은 탭에서** 돕니다. 그림에 시간을 다 쓰면
`poseLoop` 이 굶습니다. 그래서 두 가지를 했습니다.

1. **구역별 굽기** — 색이 같은 조각을 22칸 구역 단위로 합칩니다.
   드로우콜 **3,251 → 92~320**. 구역으로 쪼갰기 때문에 시야 밖은
   절두체가 그대로 잘라 냅니다(한 덩이로 합치면 이게 죽습니다).
   삼각형도 1,330,000 → 250,000~830,000.
2. **안 보이면 안 그립니다** — `document.hidden` 이면 프레임을 건너뜁니다.
   30fps 아래로 떨어지면 해상도를 한 단계 내립니다.

실내는 들어갈 때 처음 한 번만 세우고 캐시합니다.

## [붙일 자리 — 여기가 다음 사람 몫입니다]

기능은 2D 월드(`prototypes/openworld/index.html`)에 이미 다 있습니다.
3D 는 **그림과 이동**만 맡고, 패널은 그대로 부르면 됩니다.

- `spots.js` — 말 걸 자리 31곳이 좌표와 문구만 갖고 있습니다.
  `index.html` 의 `openPanel(s)` 한 군데에서 2D 의 패널을 부르면 끝입니다.
- `window.deskfit3d.setPosture(k)` — 0(곧음)~1(무너짐).
  민철님 자세 엔진의 출력을 여기 그대로 넣으면 캐릭터가 같이 굽습니다.
  지금은 시연용 곡선이 돌고 있고, 이 함수를 한 번 부르면 시연 곡선이 꺼집니다.
- 얼굴 창 안에 `<video>` 를 겹치면 웹캠과 캐릭터가 한 자리에 옵니다.
