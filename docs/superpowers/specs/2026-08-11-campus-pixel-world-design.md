# 캠퍼스 픽셀 월드 1차 설계

## 목표

기존 `/campus` 영토전 화면을 유지하면서 `/campus/world`에 첫 번째 픽셀 메타버스 공간을 추가한다. 1차 범위는 기숙사 개인 공간, 거북이·기린 캐릭터, 키보드 이동, 기본 충돌, 대기·걷기·앉기 모션, 이름·학교·레벨 표시다.

채팅, 친구 방문, 상점, 랭킹, 실시간 멀티플레이는 월드 기본기가 안정된 뒤 별도 단계로 추가한다.

## 구조

React가 페이지와 UI를 담당하고 Phaser가 월드 캔버스를 담당한다.

```text
/campus
  기존 영토전 화면

/campus/world
  React 페이지
  ├─ 뒤로가기·장소명·나가기 UI
  ├─ Phaser 픽셀 월드
  │  ├─ 기숙사 타일맵
  │  ├─ 충돌 영역
  │  ├─ 캐릭터
  │  └─ 월드 오버레이
  └─ 키보드 조작 안내
```

- Phaser: 맵, 이동, 충돌, 애니메이션
- React: 라우팅, UI, 접근성 안내
- Supabase: 후속 단계에서 위치·채팅·친구·세션 저장
- 카메라 영상이나 프레임은 저장·전송하지 않는다.

초기 버전에서는 네트워크 위치 동기화를 사용하지 않고 로컬 캐릭터 한 명만 렌더링한다.

## 맵 규격

- 기본 타일: 16×16 픽셀
- 표시 배율: 정수 배율 3배 우선
- 논리 맵 크기: 약 40×24 타일
- 충돌: 벽·침대·책상·장식물·맵 경계
- 이동: 타일 단위 기준
- 맵: 침대, 책상, 장식, 개인 공간, 출입문으로 구성된 단일 기숙사 방

맵 데이터와 충돌 데이터는 코드에 흩어놓지 않고 월드 씬이 읽는 별도 데이터로 둔다. 이후 복도·학생회관·광장도 같은 타일 규격으로 확장한다.

## 캐릭터 규격

첫 대상은 거북이와 기린이다.

- 프레임: 16×24 픽셀
- 투명 배경, 1픽셀 외곽선, 안티앨리어싱 없음
- 발 위치를 하단 중앙에 고정
- 정수 배율로만 표시
- 이름·학교·레벨은 캐릭터 위 HTML 오버레이로 표시
- 학교 색상은 이름표와 액세서리에 적용하고 몸 전체는 유지

초기 애니메이션:

- `idle`: 2프레임
- `walk-down`: 4프레임
- `walk-up`: 4프레임
- `walk-side`: 4프레임
- `sit`: 2프레임

월드 아바타는 기존 성장 단계 에셋과 당장은 분리한다. 이후 레벨·아이템 시스템과 스킨을 연결할 수 있도록 캐릭터 키와 에셋 버전을 별도로 유지한다.

```ts
type WorldCharacter = {
  characterKey: "turtle" | "giraffe";
  displayName: string;
  schoolName: string;
  schoolColor: string;
  level: number;
  position: { x: number; y: number };
  animation: "idle" | "walk" | "sit";
};
```

## 입력과 상태

- WASD·방향키: 이동
- Space: 앉기/일어나기
- 이동 중: 걷기
- 입력이 없을 때: 대기
- 앉은 상태: 앉기
- 출입문 근처: 나가기 안내

```text
idle ── 이동 입력 ──> walking
walking ── 입력 해제 ──> idle
idle ── Space ──> sitting
sitting ── Space ──> idle
```

## 1차 완료 기준

- `/campus/world`로 진입 가능
- 픽셀 기숙사 맵이 표시됨
- 거북이·기린 중 하나가 표시됨
- WASD·방향키로 이동 가능
- 벽·가구를 통과하지 않음
- idle·walking·sitting 전환이 동작함
- 이름·학교·레벨이 표시됨
- 기존 `/campus`와 다른 기능에 영향이 없음
- `npm run typecheck`, `npm run build`, 관련 테스트 통과

## 후속 단계

1. 캐릭터 에셋과 타일맵 제작
2. Phaser 월드 초기화 및 라우트 연결
3. 이동·충돌·모션 구현
4. 친구·채팅·공용 공간
5. Supabase Realtime 위치·상태 동기화
6. 상점·아이템·랭킹·시즌 이벤트

## 에셋 및 라이선스

팀원이 제공한 화면은 색감, 시점, UI 밀도 참고용으로 사용한다. 외부 게임이나 에셋의 픽셀 타일·캐릭터를 그대로 복사하지 않고, 사용 라이선스가 명확한 자체 제작 또는 승인된 에셋만 저장소에 추가한다.
