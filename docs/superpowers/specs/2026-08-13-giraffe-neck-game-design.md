# 기린 목 펴기 미니게임 설계

## 목표

미니게임존의 첫 번째 게임을 거북이 등껍질 균형에서 기린 목 펴기로 교체한다. 플레이어는 10초 안에 연속 입력으로 고개 숙인 기린의 목을 목표 자세까지 펴야 한다.

## 게임 흐름

1. 게임 패널을 열면 고개를 숙인 기린과 10초 카운트다운이 표시된다.
2. Space 또는 마우스 클릭을 누를 때마다 목 각도가 한 단계씩 펴지고 진행 게이지가 오른다.
3. 입력이 없으면 목이 천천히 다시 숙여져 제한 시간 안에 꾸준히 입력해야 한다.
4. 목표 자세에 도달하면 성공 화면과 다시하기 버튼을 표시한다.
5. 10초가 지나면 실패 화면과 다시하기 버튼을 표시한다.

## 구현 범위

- 기존 단일 HTML 프로토타입의 `shellBalance` 패널과 상태를 재사용한다.
- 외부 라이브러리나 이미지 에셋 없이 HTML/CSS 도형으로 기린을 표현한다.
- Space와 클릭은 동일한 입력 함수를 사용한다.
- 코인 보상은 이번 변경에 포함하지 않는다.
- 변경은 로컬에만 남기며 커밋하거나 원격에 푸시하지 않는다.

## 검증

- HTML 내부 JavaScript 문법 검사
- 변경분 whitespace 검사
- 로컬 브라우저에서 패널 열기, Space 입력, 클릭 입력, 성공/실패 상태 확인
