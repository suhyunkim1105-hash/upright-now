# 거북이 미로 탈출 설계

## 목표

기존 `거북이 등껍질 퍼즐` 슬롯을 `거북이 미로 탈출`로 교체한다. 새 맵 슬롯은 만들지 않는다.

## 규칙

- 10×10 미로에서 거북이를 시작점에서 출구까지 이동한다.
- 방향키와 `W/A/S/D`, 화면 방향 버튼을 지원한다.
- 벽 칸으로는 이동하지 않는다.
- 60초 안에 출구에 도착하면 `성공!`과 `+5P`를 한 번만 지급한다.
- 시간 초과 시 실패 문구와 다시 시작 버튼을 표시한다.
- 성공·실패 후에는 타일/이동 입력을 무시하고 닫기와 다시 시작만 허용한다.
- 미로는 매번 생성하되 시작점과 출구가 연결되도록 DFS 방식으로 만든다.

## 구현 방식

`prototypes/openworld/index.html`의 기존 `shellSlide` 패널 상태와 이벤트 연결부를 `turtleMaze` 상태·함수로 교체한다. 런타임 의존성은 추가하지 않는다. 미로 생성 아이디어와 게임 구조는 MIT License로 공개된 [muthuspark/javascript-games](https://github.com/muthuspark/javascript-games)의 Maze Game을 참고하고, 코드는 현재 프로젝트에 맞게 독립 작성한다.

## 검증

- 새 게이트와 패널 제목이 `거북이 미로 탈출`인지 확인한다.
- 생성된 미로에 시작점부터 출구까지 경로가 존재하는지 확인한다.
- 클릭/방향키/WASD 이동, 벽 충돌, 타이머, 성공, 실패, 재시작을 확인한다.
- JS 문법 검사, `git diff --check`, 브라우저 콘솔 오류 검사를 통과한다.
