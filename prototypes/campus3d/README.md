# 기린캠퍼스 — 3D 오픈월드

`index.html` 을 열면 끝입니다. 서버도 빌드도 없습니다.
배포본에서는 `/prototypes/campus3d/index.html`.

```
prototypes/campus3d/index.html      ← 걸어 다니는 월드
prototypes/campus3d/campusview.html ← 섬 전체 한 장 (배치 확인용)
prototypes/campus3d/buildings.html  ← 건물 한 채씩 크게 (?b=mainHall|library|dorm|union|arcade|shop)
prototypes/campus3d/interiors.html  ← 방 한 칸씩 크게 (?r=library|mainhall|dorm|union|arcade|shop)
prototypes/campus3d/lineup.html     ← 캐릭터 여덟 종
```

## 왜 3D 인가

UXI 교수님 지적 넷을 그대로 반영한 판입니다.

| 지적 | 이 판에서 |
|---|---|
| 월드맵을 할 거면 3D 로 크게 | three.js 실시간 3D. 걷고, 들어가고, 시점을 돌립니다 |
| 기숙사방도 싸이월드처럼 3D | 방 여섯이 전부 3D. 잘라 낸 아이소메트릭 방 |
| 1인칭도 되어야 | <kbd>Tab</kbd> 로 3인칭 ↔ 1인칭 |
| 걷는 걸 최소화 | 광장에서 문까지 5~9칸. 섬 반지름 40 |
| 도서관·본관이 메인이니 크게 | 그 둘만 1.22배 |
| 중앙 표지판 날리고 동상 + 분수 | 거북이·기린 청동상이 분수 가운데 |
| 호수·운동장 삭제 | 삭제. 그 자리는 소풍 마당과 정문 |
| 웹캠이 주된 기능인데 희미하다 | 오른쪽 위 **얼굴 창(PiP)**. 여기에 웹캠 화면을 겹치면 됩니다 |

## 3D 로 오면서 달라진 것

**옷이 207장에서 19벌로 줄었습니다.** 2D 는 종마다 옷을 따로 잘라야 했습니다
(8종 × 아이템 = 47 기본 + 160 맞춤 = 207장). 3D 는 몸이 여덟 종이 똑같아서
옷 하나를 만들면 여덟이 다 입습니다. 아래 종 고르기 줄에서 눌러 보면 바로
바뀝니다 — 이게 스프라이트로는 못 하는 일입니다.

## 속도

이 월드는 **웹캠 자세 추정과 같은 탭에서** 돕니다. 그림 그리는 데 시간을
다 쓰면 `poseLoop` 이 굶습니다. 그래서 두 가지를 합니다.

1. **구역별로 굽습니다** — 색이 같은 조각을 22칸짜리 구역 단위로 합칩니다.
   드로우콜 3,251 → 92~320, 시야 밖은 절두체가 잘라 냅니다.
2. **탭이 안 보이면 안 그립니다.** 30fps 아래로 떨어지면 해상도를 한 단계
   내립니다.

## 아직 안 붙은 것

- 말 걸 자리는 **문구만** 있습니다. 실제 기능(세션 · 상점 · 미니게임 · 시간표)은
  2D 월드(`prototypes/openworld/index.html`)에 있고, 여기서는 `spots.js` 의
  자리에 그 패널을 부르면 됩니다.
- 얼굴 창에 웹캠 화면이 아직 안 겹칩니다.
- 저장은 종·옷 선택만 (localStorage).
