# 기린캠퍼스 — 3D 오픈월드

`index.html` 을 열면 끝입니다. 서버도 빌드도 없습니다.
배포본에서는 `/prototypes/campus3d/index.html`.

```
prototypes/campus3d/index.html      ← 걸어 다니는 월드
prototypes/campus3d/campusview.html ← 섬 전체 한 장 (배치 확인용)
prototypes/campus3d/buildings.html  ← 건물 한 채씩 크게 (?b=mainHall|library|dorm|union|arcade|shop)
prototypes/campus3d/interiors.html  ← 방 한 칸씩 크게 (?r=library|mainhall|dorm|union|arcade|shop)
prototypes/campus3d/lineup.html     ← 캐릭터 여덟 종
```

## 왜 3D 인가

UXI 교수님 지적 넷을 그대로 반영한 판입니다.

| 지적 | 이 판에서 |
|---|---|
| 월드맵을 할 거면 3D 로 크게 | three.js 실시간 3D. 걷고, 들어가고, 시점을 돌립니다 |
| 기숙사방도 싸이월드처럼 3D | 방 여섯이 전부 3D. 잘라 낸 아이소메트릭 방 |
| 1인칭도 되어야 | <kbd>Tab</kbd> 로 3인칭 ↔ 1인칭 |
| 걷는 걸 최소화 | 광장에서 문까지 5~9칸. 섬 반지름 40 |
| 도서관·본관이 메인이니 크게 | 그 둘만 1.22배 |
| 중앙 표지판 날리고 동상 + 분수 | 거북이·기린 청동상이 분수 가운데 |
| 호수·운동장 삭제 | 삭제. 그 자리는 소풍 마당과 정문 |
| 웹캠이 주된 기능인데 희미하다 | 오른쪽 위 **얼굴 창(PiP)**. 여기에 웹캠 화면을 겹치면 됩니다 |

## 화면 껍데기 — 한 벌로 다시 짰습니다

전 판은 크림색 상자 여섯 개가 네 귀퉁이에 따로 떠 있었고, 종·옷 고르는 줄이
화면 아래에 **항상** 깔려 있었으며, 미니맵이 초록 동그라미라 지도로 읽히지
않았습니다. 지금은

- **어두운 유리 한 겹**으로 통일했습니다. 밝은 월드 위 어디에서도 읽힙니다.
- 오른쪽에 **한 기둥** — 지도 · 얼굴 창 · 접속 상태.
- 아래 가운데에 **한 줄(독)** — 지도 · 표현 · 채팅 · 옷장 · 시점 · 도움.
- 설정(종 · 옷 · 이름)은 전부 **옷장 창** 안으로 들어갔습니다.
- 지도는 바다·모래·길의 위계와 어두운 알약 이름표로 다시 그렸습니다.
  미니맵과 큰 지도가 **같은 그림**을 축척만 바꿔 씁니다.

## 미니게임 넷 — 직접 그리지 않습니다

손으로 캔버스에 그린 「기린 목 펴기」와 「달리기 100m」는 막대 하나에 네모
몇 개라 게임이 아니라 시연이었습니다. 넷 다 **이미 만들어져 돌아가는 것**으로
바꿨습니다.

| 자리 | 게임 | 어디서 왔나 |
|---|---|---|
| 도서관 책수레 · 오락실 | 동물 짝 맞추기 | 2D 월드의 `animal-find-engine.mjs` 그대로 |
| 오락실 | 동물 셋 지우기 | 2D 월드의 `animal-match3-engine.mjs` 그대로 |
| 오락실 | 동물 러너 | 같은 레포의 **Phaser** 게임 `animal-runner-game.mjs` 그대로 |
| 오락실 | 2048 | 규칙을 **MIT 오픈 소스**로 가져왔습니다 (`vendor/2048-logic.js`) |

`vendor/2048-logic.js` 는 winsonwq/2048term (npm `2048@0.2.2`, MIT) 의
`row_calc.js` · `table_calc.js` 입니다. require/export 만 ESM 으로 바꿨고
**규칙 코드는 한 줄도 고치지 않았습니다.** 원본에 mocha 시험이 붙어 있습니다.
Phaser 는 1.2MB 라 러너를 열 때만 `import()` 로 받아옵니다 — 월드 첫 화면이
느려지지 않습니다.

## 방은 통로부터 그립니다

전 판은 예쁜 스크린샷을 기준으로 가구를 놓았습니다. 그 결과 방마다 걸을 수
있는 바닥이 **7~26%** 뿐이었고, 문 앞 시작 자리가 여섯 중 넷에서 가구 안에
박혀 있어 한 발짝도 못 움직였습니다. 지금은 `CORRIDORS` 를 먼저 적고 가구를
그 바깥에만 놓습니다. `diagroom.html` 이 침범한 가구를 이름으로 집어 주고,
문에서 물을 채워 모든 자리에 닿는지 검사합니다.

> 지금: 걸을 수 있는 바닥 **50.8~62.4%**, 말 걸 자리 **전부 닿음**.

가구가 방 밖으로 삐져나오지 않는지, 사람이 벽 밖에 서 있지 않은지는
`audit.html` 이 모든 조각의 경계상자를 방 크기와 대 봅니다.
소파는 **탁자를 보고** 앉습니다 — 전 판은 열린 앞모서리를 보고 있어서
등받이가 방 안쪽이었습니다.

## 3D 로 오면서 달라진 것

**옷이 207장에서 여섯 벌로 줄었습니다.** 2D 는 종마다 옷을 따로 잘라야 했습니다
(8종 × 아이템 = 47 기본 + 160 맞춤 = 207장). 3D 는 몸이 여덟 종이 똑같아서
옷 하나를 만들면 여덟이 다 입습니다. 옷장(<kbd>C</kbd>)에서 눌러 보면 바로
바뀝니다 — 이게 스프라이트로는 못 하는 일입니다.

## 속도

이 월드는 **웹캠 자세 추정과 같은 탭에서** 돕니다. 그림 그리는 데 시간을
다 쓰면 `poseLoop` 이 굶습니다. 그래서 두 가지를 합니다.

1. **구역별로 굽습니다** — 색이 같은 조각을 22칸짜리 구역 단위로 합칩니다.
   드로우콜 3,251 → 92~320, 시야 밖은 절두체가 잘라 냅니다.
   (다 하나로 합치면 절두체 컬링이 죽습니다. 그래서 구역 단위입니다.)
2. **탭이 안 보이면 안 그립니다.** 30fps 아래로 떨어지면 해상도를 한 단계
   내립니다.

## 실시간

`net.js` 가 Supabase Realtime 채널 `world3d:<구역>` 에 붙습니다. presence 로
누가 있는지, broadcast 로 위치(10Hz) · 말 · 감정표현을 주고받고, 받은 위치는
130ms 늦춰 보간합니다. 8초 안에 못 붙으면 **완전히 포기하고** 혼자 모드로
돕니다 — 재시도를 계속하면 배터리만 먹습니다. 쓰는 열쇠는 공개용 `anon`
열쇠뿐이고 RLS 가 지킵니다.

## 아직 안 붙은 것

- 얼굴 창에 **웹캠 화면이 아직 안 겹칩니다.** 자리는 `#pip` 이고,
  `window.deskfit3d.setPosture(0~1)` 로 자세 점수를 넣으면 캐릭터가 굽습니다.
- 명예의 전당 · 초대 코드 · 학교 색은 2D 월드(`prototypes/openworld/`)에만
  있습니다. 서버 집계가 필요해서 여기로 옮기지 않았습니다.
- 장소별 앰비언트 소리는 아직 없습니다(감정표현 소리만 있습니다).
- 저장은 이 브라우저 안에서만 (`localStorage['girin3d.save']`).
