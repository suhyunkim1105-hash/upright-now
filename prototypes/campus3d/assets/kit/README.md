# 외부 3D 에셋 — Kenney CC0 킷

## 무엇이 들어 있나

| 킷 | 개수 | 무엇 |
|---|---|---|
| `city-*` | 31 | 건물 겉모습 — Large / Low / Small Building, Skyscraper, Low Wide, 표지판 |
| `furniture-*` | 116 | 실내 가구 — 책상·의자·책장·소파·주방·조명·계단·러그·화장실 |

합계 147개 · 4.1MB · **평균 28KB**

## 왜 이건 써도 되는가

앞서 외부 에셋을 기각했던 근거는 "재질이 갈라진다" 였고, 그 판단은
**비교용으로 고른 모델이 틀렸기 때문에** 나온 것입니다. 그때 세워 본 것은
사진 기반 PBR 텍스처를 쓰는 모델(LittlestTokyo)이라 당연히 갈라졌습니다.

Kenney 킷을 열어 보면 다릅니다.

```
메시 1 · 재질 5 · 텍스처 0 · 이미지 0
재질: { baseColorFactor: [0.28, 0.29, 0.33, 1], metallicFactor: 0, roughnessFactor: 1 }
```

**텍스처가 한 장도 없습니다.** 재질이 색 하나와 거칠기뿐이고, 이건 우리
`M(color, roughness)` 와 구조가 같습니다. 147개 전부 확인했고 텍스처를
가진 것은 0개입니다.

즉 이 킷은 우리와 **같은 렌더 언어**로 만들어졌습니다. 색만 우리 팔레트로
바꾸면 우리가 그린 것과 구분이 안 갑니다.

## 라이선스

전부 **CC0** (Kenney). 표기 의무가 없고 상업 이용·수정·재배포가 됩니다.
받을 때 CC0 이 아닌 것은 건너뛰도록 해 두었습니다 — `manifest.json` 의
`lic` 가 전부 `CC0` 인지 확인하고 쓰십시오.

출처: [Kenney](https://kenney.nl/assets/category:3D) · 배포 [Poly Pizza](https://poly.pizza/u/Kenney)

## 쓸 때 지킬 것

1. **색을 우리 팔레트로 다시 칠합니다.** Kenney 원본 색을 그대로 쓰면
   채도가 우리보다 높아 튑니다. `baseColorFactor` 를 읽어 가장 가까운
   우리 색으로 바꿉니다.
2. **같은 모델은 인스턴싱합니다.** 벤치 40개를 GLTF 40번 붙이면
   드로우콜 40 개입니다.
3. **`userData.noBake`** 를 답니다 — bake 가 합치면 안 됩니다.
4. 형상이 코드인 것(캐릭터·건물 여섯)은 **그대로 둡니다.** 이 킷은
   배경과 실내를 채우는 용도입니다.

## 받는 방법

`scratchpad/fetch-kit.mjs` 가 번들 페이지에서 모델 목록을 읽고 GLB 를
내려받습니다. 다른 킷을 더하려면 그 파일의 `BUNDLES` 에 줄을 추가합니다.
