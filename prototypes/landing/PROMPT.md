# 기린캠퍼스 — 랜딩 페이지 슈퍼 프롬프트

공급된 자산 목록과 이 문서만으로 **프로덕션 품질의 데스크톱 단일 페이지
랜딩**을 만든다. 레퍼런스는 듀오링고 랜딩의 **구조**(마스코트 히어로 →
교차 특징 블록 → 캐릭터 → CTA 반복)이며, 시각 언어는 듀오링고가 아니라
아래 디자인 체계를 따른다. 목업이 아니라 실제 동작하는 코드를 만든다.

## 산출물과 제약

- **파일 하나**: `prototypes/landing/index.html`. 빌드 없음, 서버 없음,
  브라우저로 열면 끝. 옆의 `assets/` 폴더만 상대경로로 읽는다.
- **외부 네트워크 요청 0.** GSAP 3.12(+ScrollTrigger)는 파일 안에
  인라인하고 라이선스 주석을 남긴다. 서체는
  `../../upright-now/public/fonts/wanted-sans/WantedSansVariable.css` 를
  링크한다(온보딩·월드와 같은 방식).
- **데스크톱 전용.** 1440×900 이 기준, 1280×768 에서 잘리지 않아야 한다.
  모바일 분기를 만들지 않는다. 뷰포트 1024px 미만이면 화면 중앙에
  "PC 에서 열어 주세요" 안내 하나만 보여 준다.
- CTA 는 전부 `../onboarding/index.html` 로 간다.
- **픽셀 아트는 월드 데모 영상·스크린샷 안에서만 존재한다.** 랜딩의
  장식 일러스트·아이콘·다이어그램은 전부 비픽셀(부드러운 벡터·일러스트)
  이다. 픽셀을 장식으로 흉내 내지 않는다.

## 디자인 체계

온보딩·월드와 **같은 값**이다. 랜딩에서 새 색·새 서체를 만들지 않는다.

```css
:root {
  --teal-50:  #EFFBF9;
  --teal-100: #CFF2ED;
  --teal-200: #ADEBE2;
  --teal-300: #8AE5D9;
  --teal-400: #56DCCA;
  --teal:     #2DD4BF;   /* 주색 — 채움에만. 이 위 글자는 먹 */
  --teal-600: #12A592;   /* 눌림·호버 — 먹 글자 5.02 */
  --teal-700: #0D7769;   /* 흰 위 청록 글자 5.25 — AA */
  --teal-800: #0C5A4F;
  --bg:        #FFFFFF;
  --ink:       #2B3230;  /* 흰 위 13.11 */
  --ink-2:     #5C6663;  /* 5.94 */
  --ink-3:     #6E7876;  /* 4.55 — 작은 글자 하한 */
  --line:      #E8EBEB;
  --line-2:    #DCE0E0;
  --surface:   #FFFFFF;
  --surface-2: #F7F8F8;
  --surface-3: #EFF1F1;
  --r:  10px;  --r-lg: 16px;
  --sh:    0 8px 24px rgba(20, 40, 38, .10);
  --sh-lg: 0 24px 56px rgba(20, 40, 38, .16);
  --ease-out: cubic-bezier(.2, .9, .3, 1);
}
```

- 서체는 **Wanted Sans Variable 하나**. 제목은 굵기(800)와 크기, 자간
  `-0.02em` 으로만 위계를 만든다. 세리프·픽셀 서체를 섞지 않는다.
- 강조색은 **청록 하나.** 두 번째 강조색을 도입하지 않는다. 리듬은
  섹션 배경을 `--bg` ↔ `--surface-2` ↔ `--teal-50` 으로 오가며 만든다.
- 제목은 `clamp()` 유동 크기. 본문 15~16px, 행간 1.7.
- 문구는 전부 **해요체.** 제품이 존대한다. 명령형·반말 금지.
  점수·등급·의료 표현 금지("자세 점수", "교정", "치료" 같은 말을 쓰지
  않는다 — 이 제품은 점수를 매기지 않는 것이 정체성이다).

## 사이트 전역 동작

- 로더 없음. 첫 화면이 곧 히어로다.
- 커스텀 커서 없음. mix-blend-mode 트릭 없음.
- 등장 연출은 `IntersectionObserver` 로 24px 상승 + 페이드, 240ms,
  `--ease-out`, 요소 간 지연 55ms. **transform·opacity 외 속성을
  애니메이션하지 않는다.**
- `prefers-reduced-motion: reduce` 에서 모든 연출을 끄고 내용은 전부
  보인다. 스크럽 구간도 최종 상태로 펼쳐진다.
- 키보드 포커스 `:focus-visible` 2px 청록 외곽선. 앵커 이동은 smooth.
- 화면 밖 영상은 `IntersectionObserver` 로 일시정지(임계 0.35).

### 모션 예산 — 상한

| 항목 | 상한 |
|---|---|
| 스크럽(핀·스티키) 구간 총합 | **400vh 이하** |
| 동시 재생 영상 | **1개** |
| 상호작용 피드백 | 200ms 이하 |
| 무한 루프 연출 | GPU 속성만, 화면 밖에서 정지 |
| blur·backdrop-filter 애니메이션 | 금지 |

이 페이지의 다음 화면은 카메라 권한과 판정 모델 다운로드다. 랜딩이
GPU 를 태우면 제품이 하는 약속(저사양 모드까지 만든 제품)과 어긋난다.

### 생성 자산 사양 — Higgsfield 에 넣을 조건

세 캐릭터는 **같은 템플릿**으로 생성한다. 한 컷씩 다른 손으로 그리면
같은 세계의 친구로 안 읽힌다.

- 공통: 부드러운 라운드 벡터 일러스트, 플랫 셰이딩 + 한 단계 음영,
  외곽선 없음 또는 몸색보다 한 톤 어두운 가는 선, **투명 배경**,
  정면 3/4, 밝은 표정, 2048px 이상, 픽셀·복셀·8bit 스타일 금지
- 색: 각 캐릭터의 몸색은 월드 시트에서 뽑은 값을 기준으로 —
  기린 `#F08C32` 계열, 거북이 `#8CD296` 계열, 펭귄 남색+흰 배
- 소품·배경·글자 넣지 않기 — 배경과 소품은 랜딩 코드가 책임진다
- 참조 이미지로 32×48 시트의 down 프레임을 최근접 확대(×16)해 함께
  넣는다 — 비율(등신 2.56, 머리 39%)을 지키게 하는 닻이다

`world-demo.mp4` 인코딩: H.264 MP4, 24~30fps, 1440×900, **15MB 이하**
(단일 폴더 배포라 무게가 곧 로딩이다), 오디오 트랙 없음.

- 실루엣 6종은 별도 자산이 아니다 — 생성한 캐릭터 PNG 에
  `filter: brightness(0); opacity: .16` 을 걸어 만든다.
- 카메라 약속 다이어그램은 **인라인 SVG 로 직접 그린다**(브라우저 상자
  안에 카메라와 판정, 밖으로 나가는 화살표에는 숫자만). 이미지 생성으로
  대체하지 않는다.

## 구현 요구

- GSAP 는 **핀 구간(섹션 2) 하나에만** 쓴다. 나머지 등장 연출은
  IntersectionObserver + CSS. `gsap.context()` 로 만들고 정리한다.
  `invalidateOnRefresh: true`, 리사이즈에서 핀이 풀리는지 확인.

```js
gsap.registerPlugin(ScrollTrigger);
const demoTl = gsap.timeline({
  scrollTrigger: {
    trigger: '#demo', start: 'top top', end: 'bottom bottom',
    scrub: 1, invalidateOnRefresh: true,
  },
});
demoTl
  .to('.demo__frame', { width: '84vw', ease: 'none', duration: .55 }, 0)
  .to('.demo__label', { opacity: 0, duration: .1 }, .35)
  .fromTo('.demo__caption', { opacity: 0, y: 24 }, { opacity: 1, y: 0, duration: .15 }, .55);
```

- 영상: `muted playsinline loop preload="metadata"` + 포스터. 화면 밖
  일시정지는 아래 형태로:

```js
new IntersectionObserver(([e]) => {
  e.isIntersecting ? video.play().catch(() => {}) : video.pause();
}, { threshold: .35 }).observe(video);
```
- 이미지에 전부 `alt`. 캐릭터 실루엣은 장식이므로 `alt=""` +
  `aria-hidden`.
- 아코디언은 버튼 요소, 화살표 키 이동까지는 요구하지 않는다.
- 코드에 한국어 주석으로 "왜"를 남긴다(이 저장소 관례).

## 완료 조건 — 숫자로 검증한다

1. 콘솔 오류 **0**, 경고 중 미로드 자산 **0**
2. 외부 네트워크 요청 **0** (서체 링크는 로컬 상대경로라 예외 아님 —
   DevTools Network 에서 원격 호스트 요청이 0이어야 한다)
3. 1440×900·1280×768 에서 가로 스크롤 **0px**
4. CTA 3곳(헤더·히어로·마지막) 모두 `../onboarding/index.html` 로 이동
5. 데모 영상: 섹션 이탈 후 `video.paused === true`
6. `prefers-reduced-motion: reduce` 에서 숨겨진 내용 **0** —
   모든 텍스트·이미지가 스크롤만으로 보인다
7. 스크럽 구간 총합 **≤ 400vh** (실측: 섹션 높이 합산)
8. 대비 위반 **0** — 본문 4.5:1, 24px 이상 제목 3:1 (토큰 주석의
   실측값을 벗어나는 새 조합을 만들지 않으면 자동 충족)
9. 픽셀 아트가 보이는 곳 **3곳 이하** (데모 영상 + 스크린샷 2장)
10. 간소화 버전에서 멈추지 않는다 — 섹션 0~7 전부, 연출 포함 구현

잰다(이 저장소가 두 번 당한 것).
