## 1. 랜딩 페이지 (신규)

`prototypes/landing/index.html` 한 장. 서버도 빌드도 없이 브라우저로 엽니다.

### 화면 순서

로더 → 히어로 → 포털 → **캠퍼스 비행** → 소개 → 매니페스토 →
카메라 약속 → 캐릭터 덱 → FAQ → CTA → 푸터

### 캠퍼스 비행 (핵심)

클립 7개(다이브 4 + 커넥터 3)를 이어 붙인 **한 번의 비행**입니다.
스크롤 위치가 영상의 재생 시간을 직접 밉니다.

이음매는 앞 클립의 **마지막 프레임을 다음 클립의 시작 프레임으로 고정**
했습니다. 그래서 장면이 바뀌어도 끊기지 않습니다.

### 이 랜딩이 저 월드라는 걸 붙인 방법

영상·이미지를 **실제 월드 화면을 참조로 물려** 만들었습니다.

| 랜딩에 나오는 것 | 월드의 무엇인가 |
|---|---|
| 도서관 ㄱ자 카운터, 열람석 스탠드 불빛 | `ZONES.library` 그대로 |
| 본관 강의석 + 뒷줄 라운지 소파 | `ZONES.mainhall` 그대로 |
| 기숙사 창가 책상 · 노트북 위 웹캠 | `ZONES.dorm` 그대로 |
| 상점 진열대 · 명예의 전당 트로피 · 게시판 | 학생회관 기능 |
| 캐릭터 덱 8종, 콜라주 픽셀 | **원본 스프라이트 그대로** |

### 한국어 · 영어

헤더 `KOR / ENG` 로 즉시 전환. 정적 문구는 사전으로, 체인 카피·매니페스토·
덱 카드는 각자 `girin:lang` 이벤트를 듣고 다시 그립니다. 선택은
`localStorage` 에 남아 다음 방문에도 유지됩니다.

### 낙서 CTA

온보딩과 **같은 wobble 필터**를 가져왔습니다. 글자는 흔들리지 않고
뒤판(`::before`)만 손그림이 되며, 누르면 종이에 붙습니다. 온보딩으로
가는 대표색 버튼 전부에 적용했습니다.

## 4. 감사와 수정

스킬 감사를 순서대로 돌리고 나온 것을 전부 고쳤습니다.

### 치명 (기능이 죽어 있던 것)

1. **체인 스크럽 좌표 버그** — 트랙 기준점을 `offsetTop` 으로 잡았는데
   이건 `offsetParent` 기준이라 0 이 나옵니다. 체인 전체가 히어로 구간에
   매핑돼 정작 체인에서는 진행도가 끝값에 고정돼 있었습니다.
   `getBoundingClientRect().top + scrollY` 로 교정
2. **장면이 카피를 덮고 있었음** — 장면 `z-index` 20~30 이 카피(10)를
   가려서 **체인 카피 4벌과 마지막 CTA 가 실주행에서 안 보였습니다.**
   장면을 워시·카피·경로점 아래(≤7)로

### 개선

- 포털 타이밍 재배분 (앞 26% 는 가만히 두고 그다음 확장)
- 카피 체류 곡선을 삼각형 → 사다리꼴로 (구간의 64% 동안 온전히 읽힘)
- 경로점 히트 영역 14 → 28px, FAQ 호버 상태 추가
- 아코디언 비대칭 이징 (열림 400ms out / 닫힘 300ms in)
- 크림 위 보조 텍스트 대비 상향, 체인 제목 h3 → h2 (위계 건너뜀 해소)
- 스크롤 후 컴팩트 스티키 헤더

### 문구

- 해요체. **점수·등급 서술 없음**
- 내부 용어 "판정" 이 방문자 카피 5곳에 노출돼 있어 전부
  "카메라가 봐 준 시간" / "기록" 으로 교체
- 가짜 통계 없음 — **"서버로 간 프레임 0장"** 카운터는 제품 사실 그대로
