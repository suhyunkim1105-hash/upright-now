## 다시 만들려면

```bash
node prototypes/landing/build/make-refs.mjs
```

월드 화면을 다시 찍습니다. 찍을 때 **HUD·멀티플레이 봇·밤 색조를 걷어냅니다** —
안 걷으면 생성 모델이 HUD 사각형을 건물로, 남의 캐릭터를 등장인물로 읽습니다.

## 한계 (알고 쓸 것)

참조를 물려도 결과는 **원본과 다른 그림**입니다. 배치·색·분위기는 넘어가지만
캐릭터 얼굴이 그대로 재현되지는 않습니다. 픽셀 그대로가 필요한 자리에는
원본 스프라이트를 페이지에서 직접 씁니다.
