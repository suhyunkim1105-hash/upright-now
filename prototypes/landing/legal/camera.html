카메라 사용 고지

서비스명Deskfit
문서 버전1.0
작성일2026년 8월 17일

웹캠을 쓰는 서비스라면 이 한 장이 가장 중요하다고 생각했습니다.

언제 켜지고, 무엇을 보고, 어디로 가지 않는지를 여기 다 적었습니다.

한 줄 요약

영상은 이 브라우저 밖으로 나가지 않습니다.

분석은 이 기기 안에서 끝나고, 프레임은 분석 직후 버려집니다.

서버로 가는 건 "몇 분 앉았는가" 같은 숫자뿐입니다.

1. 언제 켜지나요

시점카메라 상태
랜딩 페이지를 볼 때꺼짐 — 권한을 요청조차 하지 않습니다
온보딩에서 캐릭터를 고를 때꺼짐
캠퍼스(월드)에 들어갈 때켜짐 — 브라우저가 권한을 물어봅니다
캠퍼스를 걸어 다닐 때켜진 상태 유지
세션을 끝낼 때꺼짐
탭을 닫을 때꺼짐

카메라는 세션에 속합니다. 자리에 앉고 일어나는 것과 무관하게,

캠퍼스에 들어와 있는 동안 계속 켜져 있습니다.

자리에 앉으면 화면 구석에 작은 카메라 창(PIP)이 뜨는데, 이건 **표시 방식이

바뀌는 것**일 뿐 카메라가 그때 켜지는 게 아닙니다.

브라우저 탭에 표시되는 카메라 사용 중 표시등으로 언제든 확인하실 수 있습니다.

2. 무엇을 보나요

들어오면 10초 동안 지금 앉은 모습을 기준으로 등록합니다.

그다음부터는 그 기준과 지금 자세의 차이만 봅니다.

구체적으로는 어깨와 머리의 상대적 위치·거리 몇 가지를 계산해

아래 세 가지 중 하나로 셉니다.

상태뜻
좋음등록한 기준과 비슷함
주의기준에서 조금 벗어남
나쁨기준에서 많이 벗어남

이건 자세에 매기는 점수가 아닙니다. 정상/비정상도, 좋은 자세/나쁜 자세도

아닙니다. 사람마다 몸도 책상도 다르기 때문에, 우리는 "당신의 평소와

얼마나 다른가"만 셉니다.

보지 않는 것

  • 얼굴을 알아보지 않습니다 (얼굴 인식·신원 확인 기능이 없습니다)
  • 표정·감정을 읽지 않습니다
  • 화면에 무엇이 떠 있는지 보지 않습니다
  • 소리를 듣지 않습니다 (마이크 권한을 요청하지 않습니다)
  • 주변 사람이나 방 안의 물건을 식별하지 않습니다

3. 어디로 가나요 — 아무 데도 가지 않습니다

```

웹캠 → 브라우저 메모리 → 자세 계산 → 상태(좋음/주의/나쁨) 카운트 → 프레임 폐기

↓

화면 표시 (내 기기)

↓

세션 끝: 숫자 요약만 서버로

```

서버로 전송되지 않는 것

  • 영상·사진·스냅샷·녹화 파일
  • 자세 좌표(랜드마크) 원본
  • 내 평소 자세 기준값
  • 얼굴 이미지나 그로부터 만든 어떤 값

세션이 끝날 때 서버로 가는 것 (전부)

시작·종료 시각2026-08-17T14:02:00Z
학교 (선택했다면)명지대학교

이 목록이 전부입니다. 서버 저장을 켜지 않으면 이것조차 나가지 않고,

기록은 이 브라우저 안에만 남습니다.

4. 판정 모델은 어디서 도나요

자세 계산에는 Google의 MediaPipe Pose Landmarker를 씁니다.

  • 모델 파일을 처음 한 번 내려받은 뒤, 계산은 브라우저 안에서 실행됩니다.
  • 계산을 위해 영상을 Google이나 다른 곳으로 보내지 않습니다.
  • 모델 파일을 받을 때 Google 서버에 IP 주소가 남는 것은,

일반적인 웹페이지에서 이미지를 불러올 때와 같습니다.

5. 다른 사람에게 보이나요

보이지 않습니다.

같은 캠퍼스에 있는 이용자에게 보이는 것은 닉네임·캐릭터·캠퍼스 안 위치뿐입니다.

카메라 화면이나 자세 상태는 누구에게도 공유되지 않습니다.

화상 통화나 캠 공유 기능 자체가 없습니다.

6. 끄고 싶을 때

원하는 것방법
지금 당장 끄기세션을 종료하면 카메라가 함께 꺼집니다
아예 권한 회수브라우저 주소창의 자물쇠 아이콘 → 카메라 → 차단
카메라 없이 이용권한을 거부해도 캠퍼스는 걸어 다닐 수 있습니다. 자세 감지와 그에 따른 코인만 동작하지 않습니다
기록까지 지우기설정 → 전체 데이터 초기화

7. 확인하고 싶다면

말로만 약속하는 것보다 직접 보시는 게 확실합니다.

  • 네트워크 탭 — 브라우저 개발자 도구(F12) → Network에서 세션 중 오가는

요청을 전부 볼 수 있습니다. 영상 업로드가 없다는 걸 직접 확인하실 수 있습니다.

  • 오프라인 테스트 — 모델을 한 번 받은 뒤 인터넷을 끊어도 자세 감지는

계속 동작합니다. 계산이 기기 안에서 돈다는 뜻입니다.

8. 의료 목적이 아닙니다

Deskfit은 의료기기가 아니며 진단·치료를 하지 않습니다.

감지 결과는 참고 정보이며, 통증이나 불편함이 있다면 의료 전문가와 상담하세요.

자세한 내용은 이용약관 제9조를 봐 주세요.
