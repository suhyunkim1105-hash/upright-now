# 오픈소스 라이선스 고지

| | |
|---|---|
| 서비스명 | Deskfit |
| 문서 버전 | 1.0 |
| 작성일 | 2026년 8월 17일 |

Deskfit은 아래 오픈소스의 도움으로 만들어졌습니다.
각 저작물의 권리는 원저작자에게 있으며, 해당 라이선스 조건에 따라 사용합니다.

## 애니메이션

### GSAP (v3.12.5) · ScrollTrigger

- 저작권: Copyright 2008-2025, GreenSock. All rights reserved.
- 출처: https://gsap.com
- 라이선스: **GreenSock Standard License** (무료 등급)

랜딩 페이지의 스크롤 연동 모션에 사용합니다.
GSAP는 일반적인 웹사이트에서 무료로 사용할 수 있으며, 유료 구독이 필요한
Club GreenSock 전용 플러그인(SplitText, MorphSVG 등)은 사용하지 않습니다.
GSAP 코드 자체를 판매하거나 재배포용 제품에 포함하지 않습니다.

## 개발 도구

아래는 개발·검증 과정에서만 사용하며, 이용자에게 전달되는 파일에는
포함되지 않습니다.

| 이름 | 라이선스 | 용도 |
|---|---|---|
| Playwright | Apache-2.0 | 화면 검증 자동화 |
| FFmpeg | LGPL-2.1 / GPL-2.0 | 영상 인코딩·프레임 추출 |
| Node.js | MIT | 빌드 스크립트 실행 |

## 생성형 도구로 만든 에셋

랜딩 페이지의 클레이 디오라마 이미지와 영상은 아래 도구로 제작했습니다.

| 도구 | 용도 |
|---|---|
| Higgsfield (nano_banana_pro, seedance) | 캠퍼스 스틸·비행 영상 |
| OpenAI GPT Image | 일부 기능 소개 이미지 |

생성 결과물의 이용 권리는 각 서비스의 이용약관에 따르며,
Deskfit의 픽셀 캐릭터·맵·UI는 팀이 직접 제작한 창작물입니다.
