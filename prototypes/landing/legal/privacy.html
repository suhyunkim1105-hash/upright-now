Deskfit은 아직 사업자 등록을 하지 않은 학생 팀 프로젝트입니다.

이 방침은 코드를 직접 읽고 "실제로 무엇이 기기 밖으로 나가는가"를 확인해

작성했습니다. 정식 출시 전에는 전문가 검토를 받을 예정입니다.

0. 가장 먼저 알아야 할 것

카메라 영상은 이 기기 밖으로 나가지 않습니다

  • 웹캠 화면은 브라우저 안에서만 분석되고, 분석이 끝난 프레임은 즉시 버려집니다.
  • 영상·사진·스냅샷·얼굴 이미지·자세 좌표는 어떤 서버에도 저장되거나 전송되지 않습니다.
  • 서버로 보내는 것은 "몇 분 앉았는가" 같은 숫자 요약뿐입니다.
  • 자세 판정 모델(MediaPipe Pose Landmarker)은 처음 한 번 내려받은 뒤

브라우저 안에서 실행됩니다. 판정을 위해 영상을 어디에도 업로드하지 않습니다.

더 자세한 내용은 카메라 사용 고지를 봐 주세요.

1. 이 방침의 적용 범위

Deskfit은 웹캠으로 앉은 자세를 살펴 주는 온라인 자습실입니다.

캐릭터로 캠퍼스를 걸어 다니고, 자리에 앉아 공부하며, 앉은 시간만큼 코인이 쌓입니다.

이 방침은 Deskfit 랜딩 페이지, 온보딩, 캠퍼스(월드) 화면 전체에 적용됩니다.

Deskfit은 의료기기가 아니며 의료 서비스를 제공하지 않습니다.

진단·치료·통증 위험도를 판정하지 않고, 자세 점수나 정상/비정상 등급도 만들지 않습니다.

자세한 내용은 이용약관 제9조를 봐 주세요.

2. 수집하는 정보

2.1 회원가입을 요구하지 않습니다

Deskfit은 이메일·전화번호·비밀번호·이름을 받지 않습니다.

닉네임과 캐릭터만 고르면 바로 시작할 수 있습니다.

2.2 이 기기에 저장되는 정보 (브라우저 localStorage)

브라우저 저장소를 지우면 함께 사라집니다. 저장 키는 모두 girin. 으로 시작합니다.

저장 키담기는 값왜 필요한가
girin.signup닉네임, 고른 캐릭터, 학교 선택화면 표시·개인화
girin.baseline내 평소 자세의 요약 통계 — 특징별 기준값, 만든 시각지금 자세와 비교
girin.session진행 중인 세션 정보 (시작 시각, 상태별 누적 시간)새로고침해도 세션 유지
girin.sessions지난 세션 요약 목록 (최대 12개)회고 화면
girin.reward코인 잔액, 일일 획득량, 연속 출석, 보유 아이템코인·상점
girin.room내 방 꾸미기 상태, 장착한 아이템미니룸
girin.mute · girin.motion · girin.perf · girin.perfNagOff소리 끄기, 모션 블러, 저사양 모드, 안내 숨김환경 설정
girin.tutorial첫 진입 튜토리얼을 봤는지 여부중복 안내 방지
girin.landing.lang랜딩 언어 선택 (한국어/영어)다시 방문할 때 유지
girin.worldsave.auth익명 접속 토큰서버 저장을 쓸 때만 생성
girin.worldsave.queue아직 서버에 반영되지 않은 기록 대기열네트워크가 끊겼을 때 유실 방지

내 평소 자세 수치는 좌표 원본이 아니라 통계 요약입니다.

얼굴이나 신체를 복원할 수 있는 형태가 아니며, 서버로 보내지 않습니다.

2.3 서버에 저장되는 정보

서버 저장 기능은 환경 설정으로 켜고 끕니다. 꺼져 있으면 익명 계정조차

만들어지지 않으므로 서버에 아무것도 저장되지 않습니다.

서버 저장이 켜져 있을 때, 세션을 마치면 아래 값만 전송됩니다.

항목담기는 값
익명 사용자 ID자동 발급되는 임의 문자열(UUID). 이메일·전화번호와 연결되지 않습니다
세션 요약세션 ID, 학교(선택했다면), 앉은 시간(분), 캠퍼스 체류 시간(분), 회복 횟수, 시작·종료 시각
미니게임 기록어떤 게임을 했는지 (하루 1회 지급 판정용)
코인 잔액서버가 계산한 누적 코인

여기에 없는 것은 서버로 가지 않습니다. 특히 다음은 전송하지 않습니다.

  • 카메라 영상·프레임·스냅샷
  • 자세 좌표(랜드마크)·얼굴 정보
  • 내 평소 자세 기준값
  • 닉네임을 제외한 어떤 신원 정보

2.4 다른 이용자에게 보이는 정보

같은 캠퍼스에 있는 사람에게는 닉네임과 캐릭터, 그리고 캠퍼스 안 위치만

보입니다. 카메라 화면은 누구에게도 보이지 않습니다.

2.5 자동으로 만들어지는 정보

Deskfit은 광고 식별자·행동 추적 쿠키·분석 도구(Google Analytics 등)를

사용하지 않습니다.

3. 이용 목적

정보목적

법령상 의무 이행 외의 목적으로는 사용하지 않으며, **마케팅·광고·프로파일링에

활용하지 않습니다.**

4. 보관 기간과 파기

정보보관 기간파기 방법
브라우저에 저장된 모든 값이용자가 지울 때까지설정의 전체 데이터 초기화, 또는 브라우저 저장소 삭제
카메라 프레임보관하지 않음 — 분석 직후 메모리에서 폐기해당 없음
서버의 세션 요약·코인익명 계정이 유지되는 동안아래 §7 참고

브라우저 저장소를 지우면 익명 계정에 다시 접근할 방법이 없어지고,

남은 서버 기록은 어떤 개인과도 연결되지 않는 임의 문자열에만 묶입니다.

그 경우 기록은 이 기기 안에만 남습니다.

7. 이용자의 권리

언제든지 아래 권리를 행사할 수 있습니다.

  • 열람 — 브라우저 개발자 도구의 localStorage에서 저장된 값을 직접 확인할 수 있습니다.
  • 삭제 — 설정의 전체 데이터 초기화 한 번으로 이 기기의 모든 기록이 지워집니다.
  • 처리 정지 — 카메라 권한을 브라우저에서 차단하면 자세 판정이 멈춥니다.
  • 서버 기록 삭제 — 아래 문의처로 익명 ID를 알려 주시면 해당 행을 삭제해 드립니다.

(익명 ID는 설정 화면에서 확인할 수 있습니다.)

8. 만 14세 미만 아동

Deskfit은 만 14세 미만 아동을 대상으로 하지 않으며, 아동임을 알게 된 경우

관련 기록을 지체 없이 삭제합니다.

9. 쿠키와 로컬 스토리지

Deskfit은 추적 쿠키를 사용하지 않습니다. §2.2의 localStorage 값은

기능 제공을 위한 것이며, 브라우저 설정에서 언제든 지울 수 있습니다.

10. 안전성 확보 조치

  • 수집 최소화 — 카메라 영상과 좌표를 애초에 저장·전송하지 않습니다.
  • 전송 구간 암호화 — 모든 통신은 HTTPS로 이루어집니다.
  • 접근 통제 — 서버의 각 행은 발급된 익명 ID 본인만 읽고 쓸 수 있도록

행 수준 보안(RLS)이 걸려 있습니다.

  • 키 분리 — 클라이언트에는 공개용 익명 키만 두고, 관리자 키는 두지 않습니다.
  • 서버 검증 — 코인 지급량과 하루 상한은 서버가 다시 계산합니다.

브라우저에서 값을 고쳐도 지급에 영향을 주지 않습니다.

자세한 내용과 취약점 신고는 보안 정책을 봐 주세요.
