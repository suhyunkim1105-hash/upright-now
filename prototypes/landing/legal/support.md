## 지금 상태

Deskfit은 **개발 중인 학생 팀 프로젝트**입니다.
정식 서비스가 아니며, 아래를 알고 이용해 주세요.

| 항목 | 상태 |
|---|---|
| 서비스 단계 | 프로토타입 (MVP) |
| 사업자 등록 | 없음 |
| 이용료 | 무료 |
| 회원가입 | 없음 |
| 가동 시간 보장 | 없음 — 예고 없이 멈추거나 바뀔 수 있습니다 |
| 데이터 보존 보장 | 없음 — 기록이 사라질 수 있습니다 |

중요한 기록은 서비스에만 의존하지 말아 주세요.

---

## 필요한 환경

| 항목 | 필요 사항 |
|---|---|
| 기기 | **데스크톱 / 노트북** (모바일·태블릿 미지원) |
| 브라우저 | 최신 Chrome 권장. Edge·Whale 등 크로미움 계열도 동작 |
| 카메라 | 웹캠 (내장·외장 모두 가능) |
| 네트워크 | 첫 실행 시 판정 모델 내려받기에 필요 |
| 권한 | 카메라 — 자세 감지를 쓸 때만 |

Safari와 Firefox는 아직 충분히 검증하지 못했습니다.

---

## 자주 막히는 곳

### 카메라가 안 켜져요

1. 주소창의 자물쇠 아이콘 → 카메라 → **허용**으로 바꿔 주세요.
2. 다른 프로그램(화상회의 앱 등)이 카메라를 쓰고 있으면 종료해 주세요.
3. 그래도 안 되면 브라우저를 완전히 껐다 켜 주세요.

### 화면이 버벅여요

설정에서 **저사양 모드**를 켜 주세요. 그림자와 장식을 끄고 30fps로 그려서
부담이 크게 줄어듭니다.

### 기록이 사라졌어요

Deskfit은 회원가입이 없어서 기록이 **브라우저에만** 남습니다.
아래 경우 복구할 수 없습니다.

- 브라우저 저장소를 지웠을 때
- 시크릿 모드로 이용했을 때
- 다른 브라우저·다른 기기로 접속했을 때

### 자세를 잘 못 알아봐요

- 상반신이 화면에 들어오게 카메라 위치를 맞춰 주세요.
- 역광이면 인식률이 떨어집니다. 화면 쪽 조명을 밝게 해 주세요.
- 카메라 위치를 바꿨다면 세션을 다시 시작해 기준을 새로 등록해 주세요.
