# 기린캠퍼스 — 오픈월드 프로토타입

`index.html` 을 브라우저로 열면 끝입니다. 서버도 빌드도 없습니다.

```
prototypes/openworld/index.html
```

가입 흐름은 옆 폴더에 따로 있습니다 — `prototypes/onboarding/index.html`.
마지막 장에서 이 월드로 넘어옵니다. 디자인 근거(색·여백·모션·문구 규칙)는
`prototypes/DESIGN.md` 에 정리돼 있습니다.

## 무엇인가

거북목 집중 세션 도구를 **픽셀 오픈월드 캠퍼스** 위에 올린 화면·흐름
프로토타입입니다. 제품 코드가 아니라 **합의를 만들기 위한 화면**입니다 —
여기서 맞춘 것을 `upright-now/src/` 로 옮깁니다.

## 소리

음원 파일이 없습니다. Web Audio 로 그 자리에서 만듭니다 — 도서관은 깎아
낸 잡음, 광장은 밝은 화음, 본관·기숙사는 낮은 웅웅거림입니다.
브라우저 정책상 **화면을 한 번 누르거나 키를 눌러야** 소리가 납니다.
마이페이지 → 설정에서 끄고 켤 수 있고, 설정은 이 기기에 남습니다.

## 상점 아이템

`assets/items/` 는 upright-metaverse 의 `assets/03_items` 를 그대로 옮긴
것입니다. 좌표 규격은 같이 딸려 온 `assets/items/item-spec.md` 가 정답이고,
숫자를 바꾸려면 원본 저장소의 `scripts/build-items.mjs` 를 고쳐 다시 구워야
합니다. 여기서 손으로 고치면 다음 이식 때 덮어써집니다.

- 한 장이 **128x48** — 32x48 프레임 넷이 `right, up, left, down` 순서로.
- 겹치는 순서: 신발20 < 하의30 < 상의40 < 가방50 < 안경60 < 모자70.
- 과잠은 `varsity_base` + `varsity_mask` 를 학교 색으로 곱해 만듭니다.
  미리 구워 둔 빨강·파랑·초록 세 장은 대조용으로만 남겨 두었습니다.

**월드 캐릭터에는 이 그림을 안 씁니다.** 월드는 타일도 사람도 한 변 16px
(Kenney)인데 아이템은 32x48 이고, 그 안에서 옷이 쓰는 폭은 프레임의 37%
입니다. Kenney 사람은 16px 안에서 몸통이 60% 를 넘어서, 절반으로 줄여
겹치면 폭이 안 맞고 1px 아웃라인이 반 픽셀이 되어 끊깁니다. 그래서
월드에서는 입은 상의의 **색**만 몸통 줄에 반영하고, 실물 그림은 상점
인형에서 보여 줍니다. 32x48 몸통 시트가 나오면 둘을 하나로 합칩니다.

## 서버가 맡는 것 · 아직 이 기기에만 있는 것

`prototypes/shared/config.js` 에 Supabase 주소와 anon 키가 채워져 있으면
아래가 **서버로** 갑니다. 비어 있거나 `file://` 로 열면 전부 예전처럼
이 브라우저에만 남고, 화면이 그 사실을 말합니다.

| 무엇 | 어디 |
|---|---|
| 코인 잔액 · 지급 | 서버 (`world_finish_session` · `world_earn_minigame`) |
| **상점 구매** | 서버 (`world_buy_item`) — 값도 서버 값표가 정합니다 |
| **입은 것 · 옷 색 · 방에 놓은 가구** | 서버 (`world_set_loadout` · `world_set_decor`) |
| **다른 사람** | 서버 (Realtime 존별 채널) |
| 초대 코드 · 명예의 전당 | 아직 이 기기에만 |

산 목록의 정답은 **서버**입니다. 접속하면 서버 것으로 덮으므로, 서버가
붙기 전에 이 브라우저에서만 산 물건은 그때 사라집니다. 남기려면 "로컬에
있던 것을 서버에 넣어 준다" 를 해야 하는데, 그 순간 localStorage 를 고쳐
공짜로 갖는 길이 다시 열립니다 — 서버를 붙인 목적 자체가 그것을 막는
것이라 남기지 않았습니다.

오프라인에서 **사는 것만** 거절합니다. 세션 종료는 이미 일어난 사실이라
큐에 넣었다 나중에 보내도 뜻이 같지만, 사기는 결과를 모르는 부탁이라
큐에 넣으면 화면이 먼저 "샀다" 고 하게 됩니다. 입고·벗고·가구 옮기는
것은 잔액을 안 건드리므로 큐에 쌓였다가 나중에 갑니다.

초대 코드는 그대로 `localStorage` 입니다. 다른 기기에서 만든 코드는 찾을
수 없어서, 눌러 볼 수 있게 `GRN234`(연우) · `GRN567`(민철) 둘을 데모용으로
심어 두었습니다. 서버가 붙으면 `INVITE.publish / lookup / revoke` 셋만
갈아 끼우면 됩니다. 명예의 전당 순위도 예시 값이고, 내 학교 줄에만 이
기기의 진짜 기록이 더해집니다.

기숙사에서 시작합니다. 우측 상단 톱니가 **마이페이지**이고 기숙사에서만
열립니다. 좌측 하단 코랄 점이 세션 타이머이고, `세션 종료` 를 눌러야
회고가 열립니다.

## 카메라

`getUserMedia` 를 쓰므로 **크롬에서 직접 열어야** 웹캠이 붙습니다.
`file://` 에서도 동작하지만 브라우저가 카메라를 막는 환경(내장 프리뷰
패널 등)에서는 항상 거절됩니다. 세션 판정을 확인하려면 크롬에서 여세요.

**카메라는 세션에 묶여 있습니다.** 월드에 들어오면 켜지고 10초로 기준을
잡은 뒤, 걸어 다니는 동안에도 계속 봅니다. `세션 종료` 를 눌러야 꺼집니다.
의자에 앉는 것은 판정의 시작이 아니라 **웹캠 화면(PIP)을 띄우는 것**이고,
그 화면은 도서관·본관의 자리에서만 뜹니다. 카메라가 켜져 있다는 사실은
좌측 하단 세션 시계 옆 글자가 항상 말합니다 — 켜짐 / 꺼짐 / 거부됨.

## 파일

| 파일 | |
|---|---|
| `index.html` | 월드 전체. 이 한 장이 전부입니다 |
| `save.js` | Supabase REST — 세션 · 코인 · 상점 · 방 |
| `multiplayer.js` | 전송 계층 · 보간 · 이름표. Supabase Realtime, 못 붙으면 봇 |
| `chat.js` | 입력창 · 말풍선 · 최근 대화 · 반응 이모지 |
| `comfort.js` | 포커스 가두기 · 스크린리더 안내 · 대비 · 모션 줄이기 · 성능 모드 |

### ⚠ 두 갈래가 갈라져 있습니다

이 `index.html` 은 **세션·자세 쪽 갈래**입니다. 같은 파일의 다른 갈래에
멀티플레이·채팅·컴포트를 붙인 판본이 있고, 그쪽 `index.html` 은 세 js 를
읽어 들이는 스크립트 태그 셋을 갖고 있습니다. 이 판본에는 그 셋이
**없습니다** — 옆의 세 js 파일은 그대로 있지만 아직 안 읽힙니다.

합칠 때 필요한 것은 스크립트 태그 셋과 그리기 목록에 남을 끼우는 두 줄,
키보드 포커스 예외 한 줄입니다. 세 js 는 `index.html` 의 전역
(`player` · `camX` · `ctx` …)을 그대로 쓰고 스타일도 코드로 넣으므로,
`index.html` 쪽 변경면이 좁습니다.

### 멀티플레이

존마다 Realtime 채널 하나(`world:<zone>`)입니다. presence 가 "누가 있고
어떤 모습인가", broadcast 가 "어디 있나" 를 맡습니다. 위치는 초당 열 번,
그것도 **움직일 때만** 나갑니다 — 서 있으면 5초에 한 번(presence)입니다.
위치를 DB 에 쓰지는 않습니다.

나가는 것은 그리는 데 필요한 값뿐입니다: 닉네임 · 학교 · 종 · 입은 것 ·
존 · x/y · 방향 · 움직임 · 세션 시간. **카메라 프레임 · 랜드마크 좌표 ·
자세 판정 상태는 한 글자도 안 나갑니다.**

못 붙으면 연습용 캐릭터 넷이 대신 섭니다. 그때는 화면 왼쪽 위와
스크린리더 명단이 "연습용" 이라고 말합니다. 붙은 뒤에는 아무도 없어도
봇을 안 넣습니다. `?bots=8` 로 시연용으로 강제할 수 있습니다.

## 수현이 해야 하는 것 (코드로 못 하는 일)

아래 넷은 계정·키·설정이라 코드로 대신 못 합니다. 안 해도 월드는 그대로
돌고, 각 창이 "아직 안 켜졌다" 고 말합니다.

**1. Realtime 채널 잠그기 (권장)**
지금 `world:<zone>` 채널은 **공개**입니다. anon 키를 아는 사람은 누구나
들어와 아무 닉네임·아무 학교로 설 수 있습니다.
→ Supabase 대시보드 > Realtime > Settings 에서 **Realtime Authorization**
을 켜고 `realtime.messages` 에 RLS 정책을 겁니다. 그 뒤
`multiplayer.js` 의 `client.channel(...)` 에 `config.private = true` 한
줄을 더하면 됩니다.

**2. 기상청 단기예보 키 — 창밖 날씨가 진짜가 됩니다**
→ `data.go.kr` 가입 → “기상청_단기예보 ((구)_동네예보) 조회서비스”
활용신청(자동 승인, 하루 10,000회) → 마이페이지 > 인증키에서
**일반 인증키(Decoding)** 복사 → Vercel > Settings > Environment
Variables 에 `KMA_SERVICE_KEY` 로 넣고 재배포.
확인: `https://<도메인>/api/weather` 가 `{"configured":true,"ok":true,…}`
자세한 것은 `api/weather.ts` 맨 위 주석. 기본 격자는 서울(nx 60, ny 127).

**3. 스포티파이 플레이리스트 — 본관 강단 스피커**
키는 필요 없습니다. 본관 강단에서 Space → “붙여넣기” 에 스포티파이
플레이리스트 링크를 넣으면 됩니다(`open.spotify.com/playlist/…`).
기본값을 안 넣어 둔 이유: 있지도 않은 플레이리스트 id 를 박아 두면
눌렀을 때 빈 칸이 뜹니다.

**4. 구글 캘린더 — 기숙사 노트북**
키는 필요 없지만 **공개 달력이어야** 합니다. 구글 캘린더 > 설정 > 해당
캘린더 > “공개 사용 설정” 을 켠 뒤, 같은 화면 “캘린더 통합” 의
**삽입 코드** 또는 **캘린더 ID** 를 복사해 기숙사 노트북 창에 붙여
넣습니다. 비공개 달력을 넣으면 창 안에서 구글이 로그인을 막아 빈 칸이
됩니다.

3·4 는 사람마다 다른 값이라 브라우저(`girin.links`)에 남습니다. 서버로
옮기려면 `world_loadout` 같은 표를 하나 더 만들면 됩니다.

### 붙이지 않은 것

- **카카오맵** — 진짜 지도가 이 제품이 하는 일을 돕지 않습니다. 여기는
  가상 캠퍼스이고, 키 발급 + 도메인 등록 비용만 남습니다.
- **디스코드 위젯** — 위젯은 됩니다. 다만 월드의 동아리 부스는 그림일
  뿐 기능이 없고 붙일 서버도 없습니다. 자리가 생기면 그때.
- **구글 문서/드라이브 웹 게시** — 붙일 자리가 마땅치 않습니다.
  도서관에 “공유 자료” 를 만드는 건 통합이 아니라 새 기능입니다.
- 막혀 있다고 확인된 것(시도하지 않음): 노션 · 캔바 편집기 · 구글 미트 ·
  슬랙 · 에브리타임(2022년 크롤링 유죄 판례) · 링커리어 · RISS.
