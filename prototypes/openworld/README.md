# 기린캠퍼스 — 오픈월드 프로토타입

`index.html` 을 브라우저로 열면 끝입니다. 서버도 빌드도 없습니다.

```
prototypes/openworld/index.html
```

## 무엇인가

거북목 집중 세션 도구를 **픽셀 오픈월드 캠퍼스** 위에 올린 화면·흐름
프로토타입입니다. 제품 코드가 아니라 **합의를 만들기 위한 화면**입니다 —
여기서 맞춘 것을 `upright-now/src/` 로 옮깁니다.

## 지금 도는 것

| | 상태 |
|---|---|
| 캠퍼스 지도 · 건물 넷 · 실내 넷 | 됨 |
| 자세 판정 엔진 (MediaPipe, 10축, One Euro, 30초 캘리브레이션) | 됨 |
| 세션 모델 — 월드 진입이 곧 세션 시작, 의자에 앉으면 판정 시작 | 됨 |
| 세션 회고 (숫자만) | 됨 |
| 마이페이지 — 닉네임 · 학교 인증 · 자세 기준 | 됨 |
| 운동장 · 호수 · 동아리 거리 · 미니게임존 | **공간만.** 기능 없음 |
| 미니게임 (방탈출 + Ex 3) | **관문만.** 내용 없음 |
| 멀티플레이 · 상점 · 명예의 전당 · BGM | 없음 |

## 조작

| 키 | |
|---|---|
| `W A S D` | 이동 |
| `Space` | 상호작용 · 앉기 · 일어나기 · 대화 닫기 |
| `Shift` | 뛰기 |

기숙사에서 시작합니다. 우측 상단 톱니가 **마이페이지**이고 기숙사에서만
열립니다. 좌측 하단 코랄 점이 세션 타이머이고, `세션 종료` 를 눌러야
회고가 열립니다.

## 카메라

`getUserMedia` 를 쓰므로 **크롬에서 직접 열어야** 웹캠이 붙습니다.
`file://` 에서도 동작하지만 브라우저가 카메라를 막는 환경(내장 프리뷰
패널 등)에서는 항상 거절됩니다. 세션 판정을 확인하려면 크롬에서 여세요.

## 화면 크기

1440×900 과 1280×768 에서 잘리지 않는 것을 기준으로 만들었습니다.

## 에셋

`assets/` 안의 타일시트는 전부 CC0 (Kenney, OpenGameArt) 이고, 서체는
Pretendard Variable 입니다. 건물·기물·글자는 대부분 코드로 직접 그렸고
시트는 지형과 일부 소품에만 씁니다 — 출처와 라이선스는 워크스페이스
저장소의 `openworld/assets-research/ASSETS.md` 에 정리돼 있습니다.
