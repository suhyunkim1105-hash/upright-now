# 상점 아이템 좌표 규격 (32 x 48)

캐릭터 위에 겹쳐 입는 꾸미기 아이템(상의·하의·신발·모자·안경·가방)의 좌표 규격입니다.

- 상위 규격: [character-spec-common.md](character-spec-common.md) — **이 문서는 그 하위 문서입니다.**
  숫자가 어긋나면 언제나 상위 문서가 맞습니다.
- 생성 스크립트: `scripts/build-items.mjs` (의존성 없음)
- 결과물: `assets/03_items/{카테고리}/{이름}.png`
- 미리보기: `assets/03_items/preview.html`

> 숫자를 바꾸려면 이 문서가 아니라 **`scripts/build-items.mjs` 의 `Y` · `SLOT` 상수**를
> 고치고 다시 실행하세요. 스크립트가 시작할 때
> `assets/02_character/_template/layout.json` 과 대조해서 **어긋나면 멈춥니다.**

## 1. 캔버스

| 항목 | 값 |
|---|---|
| 프레임 | **32 x 48 px** |
| 프레임 수 | **4** (방향 하나씩) |
| 파일 | **128 x 48** — 가로 한 줄 |
| 배경 | 투명 PNG (RGBA8) |
| origin | (0.5, 1) — 발밑 가운데 |

### ⚠ 프레임 순서는 `right, up, left, down` 입니다

지시서에는 `down/up/left/right` 로 적혀 있었지만 **캐릭터 시트를 따라갔습니다.**
`layout.json` 의 idle 순서가 `right → up → left → down` 이라,
아이템만 `down` 을 0번에 두면 **겹쳤을 때 방향이 통째로 어긋납니다.**

```js
const DIR = { right: 0, up: 1, left: 2, down: 3 }   // 캐릭터와 동일
```

| 프레임 | 방향 |
|---:|---|
| 0 | right |
| 1 | up |
| 2 | left |
| 3 | down |

`left` 는 `right` 를 **x → 31−x 로 좌우반전**해 만듭니다 (대칭축 x15.5).
손으로 두 번 그리지 않으므로 좌우가 어긋날 수 없습니다.

> 지금은 정지 포즈 1장씩입니다. 애니메이션(52프레임)으로 늘릴 때는
> 이 4장을 각 방향 프레임에 복사하고 `dy` 만 적용하면 됩니다 (§8).

## 3. 가로 좌표 — 옷이 실제로 쓰는 폭

대칭축은 **x15.5**. 정면/뒷면과 측면의 폭이 다릅니다.

| | 정면 `down` · 뒷면 `up` | 측면 `left` · `right` |
|---|---|---|
| 옷 전체 `clothX` | **x10 – 21** (12) | **x11 – 20** (10) |
| 아웃라인 | x10, x21 | x11, x20 |
| **팔 기둥** | **x11, x20** | **x19** (right 기준) |
| 몸통 안쪽 | x12 – 19 | x12 – 18 |

측면이 1px씩 좁은 것은 상위 규격 §4 와 같습니다.

### 팔 기둥 규칙 — 손을 덮으면 안 됩니다

상의는 몸통 시트 위에 덮어 그립니다. 그래서 **몸통이 보여야 하는 자리를 비워야** 합니다.

```
        y28–30  y31–32  y33–34
        소매     팔뚝     손
긴팔     소매색   소매색   ■ 비움
반팔     소매색   ■ 비움   ■ 비움
```

- **손(y33–34)의 팔 기둥은 어떤 상의도 픽셀을 찍지 않습니다.** 스크립트가 검사합니다.
- 반팔은 팔뚝(y31–32)도 비웁니다 → 몸통 시트의 맨살이 드러납니다.
- 아웃라인(x10 / x21)은 손 줄에서도 그립니다. 실루엣이 끊기면 안 되기 때문입니다.

> **몸통 시트를 그리는 쪽에 부탁:** 팔 기둥 x11 · x20 은
> y28–30 소매, y31–32 맨살(팔뚝), y33–34 맨살(손) 로 그려주세요.
> 지금 있는 16x40 A안 몸통은 팔뚝이 없어서(소매 바로 아래가 손) **반팔이 반팔로 안 보입니다.**

## 4. 슬롯 · z 순서

좌표는 **절대 좌표** `[x0, y0, x1, y1]` (양 끝 포함). 아이템 PNG 는 32x48 캔버스 전체에
그리고 통째로 겹칩니다 — 잘라 붙이지 않습니다.

| z | 슬롯 | 영역 | `dy` | 비고 |
|---:|---|---|:-:|---|
| 20 | `feet` 신발 | **10, 44 – 21, 47** | ✕ | |
| 30 | `legs` 하의 | **10, 37 – 21, 47** | ✕ | 신발 위를 덮는다 |
| 40 | `torso` 상의 | **10, 26 – 21, 37** | ○ | 하의 허리춤을 덮는다 |
| 50 | `bag` 가방 | **8, 26 – 23, 42** | ○ | 옆·뒤로 튀어나오므로 넓다 |
| 60 | `face` 안경 | **10, 18 – 21, 20** | ○ | 머리를 따라 올라간다 |
| 70 | `hat` 모자 | **10, 14 – 21, 19** | ○ | 안착 4줄 + 술 2줄 |

`feet(20) < legs(30) < torso(40)` 순서 덕분에 발목과 허리춤이 저절로 정리됩니다.

### 가방만 `clothX` 를 벗어납니다

가방은 등 뒤로 튀어나와야 해서 **x8 – 23** 까지 씁니다.
캐릭터 안전영역 `bodyX` (x6 – 25) 안이라 프레임을 벗어나지 않습니다.

## 5. 모자 — 한 벌만 그리고 렌더러가 올립니다

목 길이가 종마다 0·1·2·4·5·6 여섯 단계라 종별로 그리면 감당이 안 됩니다.
**모자·안경은 목 0px 기준(`headTopY = 14`)으로 한 번만 그립니다.**

```ts
hat.y    = -species.neck   // 목 길이만큼 위로
glasses.y = -species.neck
```

### 지켜야 할 한 줄: 모자는 y14 위로 못 올라갑니다

기린이 `neck = 6`, `headTopY = 8` 로 이미 한계입니다.

```
모자 실제 y = 14 - neck + dy
기린 최악   = 14 - 6 + (-1) = 7      ← 타이머 예약(y<7) 바로 아래. 딱 맞습니다
```

**모자 PNG 에 y14 보다 위(y13 이하) 픽셀이 하나라도 있으면 기린이 타이머 자리를 침범합니다.**
스크립트가 검사해서 위반하면 PNG 를 쓰지 않고 멈춥니다.

아래로는 **y19 까지** 허용합니다 (학사모 술처럼 얼굴 옆으로 늘어지는 것).

## 7. 과잠 — 단색 마스크로 학교 색 적용

과잠은 학교마다 색이 달라야 해서 **색을 코드에서 갈아끼웁니다.**
파일을 두 장으로 쪼갭니다.

| 파일 | 내용 |
|---|---|
| `tops/varsity_base.png` | 학교 색이 **아닌** 부분 — 흰 소매·아웃라인·립 |
| `tops/varsity_mask.png` | 학교 색이 **들어갈** 부분만. **무채색** |

마스크는 순수 단색이 아니라 **회색 2단계**입니다. 곱셈 합성하면 음영이 공짜로 따라옵니다.

| 회색 | 뜻 |
|---|---|
| `#ffffff` (255) | 학교 색 그대로 |
| `#b0b0b0` (176) | 학교 색 x 0.69 — 그늘 |

### 합성 순서

```
1. mask 를 그린다
2. 학교 색을 'multiply' 로 덮는다      → 회색 2단계가 명암이 된다
3. mask 를 'destination-in' 으로 다시  → 알파 복원
4. base 를 'source-over' 로 올린다     → 흰 소매·립
```

Phaser 라면 마스크 스프라이트에 `setTintFill` 대신 `setTint(schoolColor)` 를 주면
같은 결과가 나옵니다 (tint 는 곱셈입니다).

**빨강·파랑·초록 3벌은 위 합성을 미리 구워둔 것**입니다
(`varsity_red.png` · `varsity_blue.png` · `varsity_green.png`).
학교 색이 이 셋 중 하나가 아니면 `base` + `mask` 를 쓰세요.

## 10. 자동 검사

```bash
node scripts/build-items.mjs
```

아래를 어기면 **PNG 를 쓰지 않고 멈춥니다.**

1. `layout.json` 과 좌표 상수가 다름 (상위 규격 드리프트)
2. `y < 7` 에 픽셀 (타이머 예약 침범)
3. 슬롯 사각형 밖에 픽셀
4. 팔레트에 없는 색
5. 모자에 `y < 14` 픽셀 (기린이 타이머 자리 침범)
6. **상의가 손(y33–34 팔 기둥)을 덮음**
7. 캔버스(128x48) 이탈

그리고 겹침 테스트를 돌려 결과를 출력합니다 (§11).
