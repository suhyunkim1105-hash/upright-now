# 방 만들기 흐름 프로토타입

제품 화면을 손으로 만져 보기 위한 **단일 파일 프로토타입**입니다.
`src/` 의 제품 코드와는 별개이고, 빌드에도 들어가지 않습니다.

여기서 흐름과 화면을 먼저 맞춘 뒤 `src/` 로 옮깁니다.

## 여는 방법

`index.html` 을 브라우저에서 그대로 엽니다. 서버가 필요 없습니다.
서체는 저장소의 `public/fonts/wanted-sans/` 를 상대경로로 불러옵니다.

## 팀원에게 링크로 넘길 때

```bash
node build-standalone.mjs
```

`standalone.html` 하나가 나옵니다. 서체를 파일 안에 base64 로 넣어 두므로
**외부로 나가는 요청이 하나도 없습니다.** 저장소에는 넣지 않습니다
(빌드 산출물이고 1.9 MB 입니다).

## 무엇이 들어 있나

| 화면 | 상태 |
|---|---|
| 홈 (방 만들기 · 방 찾기) | 동작 |
| 방 만들기 5단계 | 동작 |
| 대기실 · 세션 · 스트레칭 · 결과 | 동작 |
| 성장 · 캠퍼스 | 화면만 |
| 마이페이지 · 설정 | 동작 |

세션 시계는 실제로 흐르고, 결과·회고·경험치는 실제 경과 시간에서 나옵니다.

## 진짜가 아닌 것

- **참가자 이름** — `DEMO_MEMBERS` 한 곳에만 있습니다. `?demo=1` 일 때만 나옵니다.
- **회고 문장** — 같은 계약(`AiReportInput` → `AiSessionReport`)을 쓰지만 문장은
  `composeReport` 가 이 자리에서 만듭니다. 서버가 붙으면 그 함수만 `fetch` 로
  바꾸면 됩니다 (바로 위 주석에 코드가 있습니다). 실제 파이프라인은
  `api/ai-report.ts` 에 이미 있습니다.
- **화면에 있는 숫자** — `예시` 칩이 붙은 것은 전부 지어낸 값입니다.
