# 시각 레퍼런스 사용 지침

## 1. 캐릭터

파일: `character-growth-final.jpeg`

이 이미지는 Deskfit의 **캐릭터 디자인 최종 기준**입니다.

### 유지할 요소

- 초록색 거북이에서 노란색 기린으로 변화
- 따뜻한 3D 렌더 질감
- 둥글고 친근한 비율
- 아이보리 배경과 부드러운 그림자
- 성장 단계가 한눈에 구분되는 실루엣
- 최종 우뚝 기린의 대학 과잠과 캠퍼스 백팩

### 단계

1. 뽀각 거북
2. 꿈틀 거북
3. 빼꼼 거부기린
4. 반듯 거부기린
5. 쭉쭉 기린
6. 우뚝 기린

### 사용 금지

- 원본 한 장을 무리하게 CSS로 잘라 최종 프로덕션 에셋으로 사용
- 단계마다 다른 그림체 사용
- 초록 거북이·노란 기린 색상 체계 변경
- 빼꼼과 반듯, 쭉쭉과 우뚝의 차이를 약하게 만드는 재생성

## 2. 웹 대시보드

파일: `dashboard-ui-concept.png`

이 이미지는 대시보드의 **정보 밀도와 색상 역할**을 보여주는 기준입니다. 픽셀 단위로 복제하지 않고 디자인 시스템에 따라 재구성합니다.

### 유지할 요소

- 왼쪽 사이드바 + 중앙 주요 콘텐츠 + 오른쪽 보조 레일
- 아이보리·화이트 기반
- 핑크·노랑·파랑 파스텔 카드
- 큰 캐릭터 세션 카드
- 6단계 성장 진행도
- 출석 캘린더
- 오늘의 기록
- 친구 방 CTA
- 둥근 카드와 충분한 여백

### 수정할 요소

- 기본 세션을 30분이 아니라 25분으로 표시
- `자세 점수` 대신 회복 성공·감지 가능 시간·출석·XP 사용
- 성장하지 않은 단계는 회색 실루엣으로 표시 가능
- 세션 중 화면은 대시보드보다 훨씬 단순하게 구성

## 3. 저작권·자산 원칙

사용자가 제공한 외부 UI 이미지는 분위기 참고용입니다. 외부 서비스의 로고, 아이콘, 화면 구성, 캐릭터를 그대로 복제하지 않습니다. 최종 UI와 캐릭터 에셋은 Deskfit 전용으로 재제작합니다.
